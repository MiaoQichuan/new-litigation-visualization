# 首页展示用的虚构示例

首页「八个模块」成品墙与「案件看板」截图，都由这里的虚构示例实际跑出来。八张图各用一件案子，
人物、公司、金额、日期均为虚构，与任何真实主体无关；V6、V7 的统计数据为示例数据，非真实统计。

| 文件 | 模块 | 虚构案件 |
| --- | --- | --- |
| `v1-flow.json` | V1 诉讼可视化重画 | 证券虚假陈述责任纠纷审理流程 |
| `v2-timeline.json` | V2 时间轴大师 | 芯片技术秘密侵权纠纷，双方主张对读 |
| `v3-relations.json` `v3-choice.json` | V3 法律关系图大师 | 数据中心建设工程施工合同纠纷（实际施工人） |
| `v4-brief.json` | V4 大事记表大师 | 跨境并购股权购买协议价款调整仲裁，按争点分组 |
| `v5-case.json` | V5 庭审对抗图大师 | 投资机构诉实际控制人股权回购（对赌）纠纷 |
| `v6-rose.json` | V6 法律图表大师 | 某知识产权法院收案构成（南丁格尔玫瑰图） |
| `v7-deck/` | V7 法律课件大师 | 涉外商事仲裁受案逐年增长 |
| `v8-case/` | V8 案件看板大师 | 商业保理合同纠纷：八份材料（`materials/`）与事实清单（`facts.json`，出图时复制为「事实.json」） |

文件名一律用 ASCII：Windows 用自带的解压工具解压仓库 ZIP 时，中文文件名会解压失败。

重新出图：`bash assets/src/showcase/build.sh /tmp/nlv-showcase`，只写输出目录。
