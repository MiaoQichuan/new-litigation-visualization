# ADR 0002 — 模型不作判断，争点列留空

**状态：** 已采纳

## 背景

中国法院的审判思路是事实归事实、判断写在「本院认为」里面。事实部分掺进主观推断，
法官第一眼就会把它整体降权。

## 决策

模型不填：加黑、主要内容的删减、三方视角的摘录取舍、争点归属。
争点列在底稿生成时一律为空，由律师在 Excel 母表内填写后回填。

## 否掉的替代

- **让模型给争点归属的建议、标注「仅供参考」。** 一个可以被后续步骤读取的字段，
  标不标「参考」都会被当成结论用。下游攻防图大师按争点分组时不会区分。
- **按关键词把事实自动分到争点下。** 争点会随程序变（一审重要的再审可能不重要），
  关键词表在跨程序时必然失效。

## 后果

三件套不是一键连跑，中间有一道人工。这是明摆着的代价。
换来的是底稿里没有任何一条是模型的法律判断。

## 执行处

`scripts/check_facts.py` 的 E1/E2；`tests/break_tests.py` 两项改坏验证。
