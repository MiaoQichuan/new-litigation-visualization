# ADR 0005 — 简表：从已做好的交付物里再抽一层

**状态：** 已采纳

## 背景

新诉讼可视化这条线上，大事记表大师是唯一不出图的一件。Word 与 Excel 都是文档，
摆在其他 skill 中间显得不成套；而律师真要把一个案子的来龙去脉递到法官或当事人手里时，
Word 交付版又太长、Excel 母表又太内部。

## 决策

在管线末尾加一件产物：大事记简表，A4 竖版，呈报用。三条定死：

**一、读 渲染输入.json，与 Word、Excel 同源。** 最初绕开它、从底稿另做一遍映射，
结构立刻就与 Word 对不上：日期写法不同、序号成了 F001、备注里的标记全丢。
简表是把已做好的东西换个格式呈现，不是重新做一遍，代价也因此极小。

**二、四列与 Word 同名同序，去掉的是「备注」。** 备注一格里塞着来源、争点、关联、标记
好几段并列信息，排进图里必然乱；主要内容是一段连续原文，折行就是自然的段落折行。

**三、它是呈报件，不带任何内部痕迹。** 不出现省略号，不写「全文见 Word 交付版与 Excel 母表」，
不标「本程序新证据」「读图转写未经逐字核验」。这些东西给法官看会引出「那你为什么不给我全的」
这类疑问。相关标注在 Word 与 Excel 上保留，红线仍然守住。

主要内容超长时由代码按句读边界取，取到完整句子为止，一律以句号收尾。
这与「主要内容照录、模型不得省略」不冲突：那条管的是模型，这里是代码少取几句，
每个字仍是原文，Word 与 Excel 上的全文一字未动。

## 否掉的替代

**按字截断加省略号。** 呈报件上半句话和省略号都会让人以为被藏了东西。

**让模型概括成一两句。** 那是改写，直接撞上照录那条红线，也会把子序列核验废掉。
