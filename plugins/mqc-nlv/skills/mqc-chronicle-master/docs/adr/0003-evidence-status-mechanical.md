# ADR 0003 — 证据状态由有无证据编号机械决定

**状态：** 已采纳，**有已知缺口**

## 决策

有证据编号即「有书证」，无编号即「仅当事人陈述」，且后者必须同时进入不确定清单。
这个字段不由模型判断。

## 已知缺口（真材料上撞出两次）

1. 判决书「本院查明」里的事实，既不是书证也不是当事人陈述，是法院认定，
   现在被机械归成「仅当事人陈述」。
2. 尚未进入诉讼的合同原件没有证据编号，同样被归成「仅当事人陈述」。

二分法撑不住，至少要区分：有证据编号的、法院已认定的、材料原件但未编号的、
纯当事人陈述的。**暂按二分法运行**，等真跑几个案子后再定第三档怎么写。

## 为什么先不改

改成多档意味着模型要判断一条事实属于哪一档，那就回到了 ADR 0002 否掉的路上。
正确的解法多半是按材料的性质（来自哪份材料）机械推导，而不是按事实判断——
这需要材料清单先带上「材料性质」字段，是个结构变更，不该顺手做。
