# ADR 0002：磁吸网格与卡片模块（向 M3E Canvas 学）

状态：已采纳（0.2.0），取代 ADR 0001 的「固定版式 + 格子」部分

## 背景

0.1.0 的版式是 8 种固定页，每种页的格子坐标各写各的。作者试用后的意见：太自由、不成体系——
模块只是「放进一个框」，文字与图形对不齐，模块之间的间距每种版式都不一样，没有课件该有的呼吸感。
作者给了参考：M3E Canvas（lnkiai，MIT），一个按 Material 3 Expressive 拼手机界面的小工具，要的是它那种
「UI 设计、小程序」的感觉：零件各有样子，拖过去会被吸住，同类零件靠在一起会连成一组。

## 学了什么

| M3E Canvas 的做法 | V7 的版本 |
| --- | --- |
| 零件化：按钮、列表项、卡片……每种零件有自己的样子与尺寸 | 9 种模块（标题、正文、要点、编号卡、大数字、金句、注释、V6 图表、V1–V5 图），各有内边距、字号层级、最小尺寸、默认外观 |
| 4dp 网格吸附 | 12 栏 × 6 行的网格，坐标只能是整数格；模块间距全套统一 16px |
| 磁吸连接：两个按钮或列表项靠近就连成一组，相接处的角变小 | 相邻的同类卡片（并排等高、上下等宽）自动连成一组：间距收到 4px、内角收小、外角不变；`join: false` 拆开 |
| 磁场：进入范围后吸引力从 0 渐变到 1，零件取那一组的尺寸落下 | 编辑器里拖动时卡片被最近的格子吸过去（70px 内按距离平方渐强）；拖到同类卡片旁，按那一组的高 / 宽落下（`runSnap`） |
| 对齐参考线 | 拖动时显示整张网格与落点虚影，连上的邻居当场预览收小后的内角 |
| Tidy：一键贴边、连组、按 16dp 排开，再按一次撤销 | 整理：上推补缝、并排同类等高（于是连组）、补齐空白；幂等；可撤销 |
| Shape 轴：方角 / 圆角 / 全圆角一次切换 | 风格即形状：奇川风圆角（外 12、内 4），歸藏风直角；编辑器自己的界面也跟着变 |
| 零件面板（图标 + 名字的方块）、浮动的胶囊工具条、分节的属性面板 | 同样的编辑器骨架，用两种风格的原色与色调面 |

许可：M3E Canvas 是 MIT。我们**只学做法，代码自写**：它是 React + Next.js，我们的编辑器是单文件 HTML + 原生 JS + Python 标准库，
不装 Node、不联网；规则另有 Python 一份（拼页与导出用），两份由回归里的「规则对照」用 node 逐项比对。

## 不学的

- **自由画布**（零件可以放在任何像素上，Ctrl 拖动不吸附）：课件要整齐，坐标只许是格子。
- **多屏连线、点击跳转、预览动效**：课件是线性的一页页，导出 PPTX 后由 PowerPoint 放映。
- **种子色生成整套配色、明暗主题、对比度档位**：V7 只用两种风格的原色（与 V6 同一规矩，见 V6 ADR 0010）。
- **AI 写说明、分享链接**：材料不出电脑。

## 后果

- deck.json 升到 `mqc-nlv/deck@2`：页 = 模块列表，每个模块写格子坐标。旧的 deck@1 读入时自动升级，内容不丢。
- 模型写课件只需「挑组合、填字段」，出错面比 0.1.0 更小；用户在编辑器里拖动，规则与模型写的一致。
- 新卡片一律空着放，不填占位字；空卡片导出前被拦下，免得「写一段话」这类字进了交付件。
- 大数字卡用 V6 的数字核对：写了出处图表就推一遍，推不出就拒。
