# ADR 0003：法律垂类、AI 走对话、Logo 是唯一的图片

状态：已采纳（0.3.0）

## 背景

作者的判断：我们不可能做出比 PowerPoint 更厉害的编辑器，只能在法律垂类上做。工具会大量用 AI；
给用户的自由度是「假自由度」——用户说出想法，AI 按预设好的法律垂类模块快速做出来，用户在磁吸界面上调整，再导出 PPT。
律师和律所还需要 Logo、律所介绍、律师介绍，并据此生成介绍页。

## 决定

1. **垂类预设。** 左边的部件按法律人的需要排：法条、裁判要旨、案例、争议焦点、风险提示、证据；V1–V6 各一张图卡；
   律所的 Logo、介绍、联系方式。组合按「律所 / 法律 / 通用」分组。
2. **AI 走对话，不在编辑器里直连模型。** 编辑器把请求写进 `ai/requests.json`，对话里的 AI 用 `scripts/ai.py` 取、做、交。
   理由：对话里的 AI 能调用 V1–V6 出图、能读用户给的材料；编辑器不联网、不要 API key。结果交回前先校验，过不了课件不动；
   编辑器轮询到课件变了就刷新，并把改动前的样子放进撤销栈。（作者选了这一项；「编辑器里填 key 直连」留作以后的选项。）
3. **律所名片录一次。** 放课件目录的 `brand/` 或本机公共目录；介绍卡、联系方式卡、Logo 实时读名片。
   一键生成介绍页不需要 AI（确定性），润色再交给 AI。
4. **Logo 开例外。** PPTX 里只许有一种图片：律所 Logo（PNG / JPG，媒体名 `nlv_logo_*`，形状名 `Logo n`）。
   SVG Logo 转成形状，颜色记为品牌色。回读审计抓任何别的图片。（作者选的。）
5. **法律准确性是硬规矩，对 AI 也一样**：法条与要旨照录原文、拿不到就留空；案号不编；数字由数据推出。
   拼页对法条、要旨、金句都提醒逐字核对。

## 不做

- 编辑器里直连模型（需要 key、联网，且调不动 V1–V6）。
- 律师照片等其他位图（会破坏「全可编辑」；需要时再议）。
- 表格模块（V4 的大事记以 A4 简表 SVG 进来；可编辑表格留待下一版）。
