# ADR 0001：磁吸格子 + 可编辑 PPTX，只读兄弟模块

状态：已采纳（0.1.0）；版式部分已由 ADR 0002（磁吸网格）取代

## 背景

律师做课件，最费时的是把一张张图搬进 PPT、对齐、统一颜色，然后发现图是截图改不了。
V1–V6 已经能出可靠的图；缺的是「排成一套」和「导出后还能改」。

## 决定

1. **固定版式 + 格子。** 8 种版式，每格尺寸固定、只收指定类型的模块。不做自由画布：自由拖放的课件很难保证对齐和字号，
   也很难让模型写对。格子尺寸与 V6 的 V7 版位（module.SLOTS）一致，V6 图按格子尺寸重新出图，而不是缩放成品。
2. **一页 = 一张 1280×720 的 SVG。** 预览与导出调用同一个 `deck.compose`，编辑器里看到的就是 PPTX 里的样子。
3. **导出借 V1。** 每页走 V6 `pptx_ready` → V1 `export_pptx` → V6 `apply_alpha`，再合并成一套；合并后回读审计
   （页数、XML、无位图、颜色白名单、文字齐全），没过不交付，旧文件不动。
4. **V1–V5 只收 SVG，只缩放不改色。** 路径统一拍平成绝对坐标折线（PowerPoint 的自由曲线可编辑），
   字号随缩放、低于 11px 拒；风格由颜色识别，与课件不符就拒，请回原模块重出。
5. **只读兄弟模块。** V7 不改 V1–V6 的任何文件；回归在跑完全部测试后比对 V1–V6 的指纹。
6. **编辑器只用标准库。** `ThreadingHTTPServer` + 单文件 HTML，只听 127.0.0.1，POST 校验 Host；
   不装 Node、不联网、材料不出电脑。写文件一律「暂存 + 改名覆盖」，不靠删除（WorkBuddy 沙箱禁删）。

## 不做（第一版）

表格模块、动画、母版自定义、自定义强调色、PNG/位图模块。表格放下一版。

## 后果

版式少而稳，模型写 deck.json 出错面小；用户想要的自由度由「换版式 + 格子互换」覆盖。
V6 升级若改变了图，V7 的成品账会先红，提醒确认后 `--update`。
