# ADR 0004：律所风格从律所自己的模板来

状态：已采纳（0.4.0）

## 背景

作者的判断：律师是崇尚自由、有自己审美的职业；律所通常有自己的 PPT 模板与品牌规范。只给奇川风、歸藏风两种，
律所的课件就不像律所自己的。作者的设想：用户上传自己的标准模板或喜欢的模板，系统把它分解，在它的基础上按我们的
分析和逻辑做成磁吸编辑模块。第一份真实样本是一家大所的 104 页模板。

## 决定

1. **分三步走，每步给人看实物。** 第一步只读、出读取报告（template_read.py）；第二步生成律所风格（firm_style.py）；
   第三步（以后）把模板里的页型变成磁吸组合。
2. **作者定的三条**（2026-10-05）：中文标题用粗黑体（模板多半没写中文字体）；只用主色家族与灰，辅助色先不放，一页一处重音；
   V6 图表的重音跟着换成律所主色（V6 开一个经校验的口子，见 V6 ADR 0011）。
3. **按图本身分 Logo。** 律所常有两版 Logo（深底白字、浅底彩色）。只看「出现在哪种底色的页上」会被照片底的页骗到，
   所以解 PNG 量可见像素的亮度：很亮的是深底版。用标准库解，不装 Pillow。
4. **校验在生成时做，不在出错时补。** 正文、次要字、标题、白字、封面字的对比度都要 ≥ 4.5，主色不能是灰。
5. **模板是律所的财产**：不留存模板，只留读出的东西；仓库里的测试用虚构律所与自己导出的示例课件改出来的「模板」。
6. **V1–V5 不动。** 它们的图没有律所风格的版本，V7 不改颜色、不拒收，提醒出白描版。

## 后果

- 律所只要上传一次模板，之后每套课件都可以是「自己的样子」，而核对规矩（数字、引文、案号）不变。
- 版面网格暂时仍是 V7 的 12 × 6（页边距 48 / 56），没有跟模板的页边距（这份样本是 60）；读取结果里记下了模板的页边距，留待第三步。
- 模板里的辅助色、动画、复杂的图形页（组织结构、流程、韦恩图……）暂不搬；它们的去处是 V1–V6 的图。
