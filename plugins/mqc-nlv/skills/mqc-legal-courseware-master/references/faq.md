# 法律课件大师 · 常见问题、报错对照与限制

遇到问题先看这一份：三步上手、常见误用、报错与退出码、术语速查、已知限制都在这里。

## 一、三步上手

    python3 <本技能目录>/scripts/studio.py <本技能目录>/examples/demo     # ① 打开编辑器看示例课件（浏览器里用）
    python3 <本技能目录>/scripts/build.py 我的课件 --new                    # ② 在当前目录新建一套课件
    python3 <本技能目录>/scripts/build.py 我的课件 --check                  # ③ 导出前逐页检查；去掉 --check 即导出 PPTX

在 AI 助手里直接说：「用法律课件大师，把【材料 / 想法】做成【几页】课件，在【场合】讲给【谁】，用【奇川风 / 歸藏风】。」
由 AI 助手代开编辑器时加 `--detach`（独立运行，`--stop` 关掉）。导出的文件在 `我的课件/exports/<标题>.pptx`。

## 二、常见误用（反模式）

| 误用 | 会发生什么 | 该怎么做 |
| --- | --- | --- |
| 图表库放进来的示例数据没换就导出 | 导出前检查拦下：「这张图还是图表库里的示例数据」 | 告诉 AI 材料在哪，或在右栏改「V6 图表说明」 |
| 标题里写图表推不出的数 | 拒绝；数字要能由数据推出 | 改成原值、n 或由数据算得的数 |
| 法条、裁判要旨凭记忆写 | 「请核」逐条提醒，原文须逐字核对 | 照录您给的原文；案号不编 |
| 一张卡塞太多字 | 「字太多，放不下」，写明最小字号要几行 | 拆页、把卡片拉大或把话写短；字不小于 11px |
| 把课件存进技能目录 | 技能更新时会被整个替换 | 课件文件夹放在您自己的工作目录 |
| 在 PowerPoint 里改完又回编辑器改 | 编辑器以 deck.json 为准，PowerPoint 里的改动不回流 | 在编辑器里改好再导出；导出后的微调留在 PowerPoint |
| 自定义风格的深底页（封面、章节页）放图表 | 放不清，拼页会拦下 | 图表放在白底内容页 |
| 退出码不是 0 却交付 | 交付了没过检查的文件 | 只有退出码 0 才交付 |
| 律所模板放进开源仓库 | 模板是律所的财产 | 模板不留存，只存读出来的风格 |

## 三、报错与退出码

`build.py` 的退出码：**0** 成功；**1** 课件说明有错；**2** 有页面没准备好；**3** 导出后回读没过。不是 0 就不要交付。

| 您会看到 | 意思 | 怎么办 |
| --- | --- | --- |
| `找不到 …/deck.json：这个文件夹里还没有课件` | 路径不对，或还没新建 | 核对路径，或用 `--new` 新建 |
| `deck.json 不是合法的 JSON：第 X 行第 Y 列附近` | 多了逗号、少了引号或括号 | 按行列号改，或回编辑器改 |
| `这张图还是图表库里的示例数据` | 示例数据没换 | 交给 AI 换成您的数据 |
| `字太多，放不下（最小 … 也要 … 行）` | 卡片装不下 | 拉大卡片、拆页，或写短 |
| `要点放不下` / `证据放不下` / `数字「…」在这张卡片里放不下` | 同上 | 同上 |
| `案例卡太小，放不下案号与法院` | 案例卡太小 | 把卡片拉大 |
| `请核　…`（不是错误） | 法条、要旨、金句要逐字核对；约数、手填的大数字要人看一眼 | 原样转告用户确认 |
| 导出后回读没过（退出码 3） | 页数、颜色、图片或文字对不上 | 旧文件不动；按提示改后重导 |
| 浏览器没自动弹出编辑器 | 端口被占会自动换一个；无界面环境不弹浏览器 | 照终端打印的本机地址手动打开；由 AI 代开时用 `--detach`，`--stop` 关掉 |

## 四、术语速查

| 术语 | 一句话解释 |
| --- | --- |
| deck.json | 一套课件的全部内容，存在课件文件夹里，随时可再编辑 |
| 卡片 | 页面上的一个元素：图表、结论、要点、法条、裁判要旨、案例、大数字、Logo…… |
| 磁吸网格 | 12 栏 × 6 行，卡片自动吸附对齐 |
| 图表库 | 147 个律师常讲的问题，每个配好画法与缩略图，点一下放进当前页 |
| 读图编号 | 图上放编号，要点同号联动；导出后按编号生成讲课动画（点一下出一个） |
| 请核 | 脚本核不了的地方，交给人确认 |
| 律所名片 | 律所与律师信息填一次，介绍页、联系方式、Logo 都实时读它 |
| 自定义风格 | 从律所的模板、截图或一个主色生成；只用主色家族与灰 |

## 五、已知限制

- 只做课件里的法律图表页与常用页，不写整套演讲稿，不做视频与复杂动画。
- 法律意见本身不由它出：法条与裁判要旨照录您给的原文，案号不编。
- 案件经过时间轴、法律关系图等诉讼图要另装对应的技能；没有也不影响图表库、卡片与导出。
- 编辑器以 deck.json 为准：导出后在 PowerPoint 里的改动不会回到编辑器。
- 示例课件 `examples/demo/` 的律所、律师、数据均为虚构。

## 六、隐私与合规

- 纯本地运行：只用 Python 标准库，**不联网、不调用任何外部 API**。
- 编辑器只开在本机（127.0.0.1），非本机来的请求一律拒绝。
- 只读写这套课件的文件夹与您指定的导出路径；不收集、不上传任何数据。
- 读 PPT 模板时，若本机装了 LibreOffice，会在本机调用它转出缩略图；没装就跳过。
