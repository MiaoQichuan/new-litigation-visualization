# 变更记录

## 0.9.0 · 随套件 v2.5.0 · 编辑器改版：安静的版面，新诉讼可视化的整体界面风格

作者定的：编辑器要简洁、有高级感，不要杂乱，学对话式助手那种安静；和新诉讼可视化的整体界面是同一家——
像一张安静的白纸，靠灰度与留白分层。

**品牌（作者 10-27 定）：** 侧栏左上角换成作者的头像 + 「新诉讼可视化」字标，下面一行小字是产品名「法律课件大师」；
浏览器标签页的小图标也是头像。字标用方正小标宋（本机装了才用，不加粗），没装时用思源宋体粗体；头像是 `web/brand/` 里的两张 PNG。
导出的课件里不放这个品牌——课件上的 logo 仍是律所风格里律师自己的。

**版面（安静的对话式布局）：**
- 原来一屏同时摆着导轨、左面板、画布、右面板、底部页面条、顶栏十来个按钮。现在平时只有三样：
  左边一条侧栏（品牌、「新建一页」、七个入口——图表库、诉讼图、版式、卡片、适配、导出、更多——和全部页面），中间这一页，下面一个交给 AI 的输入框。
- **工具放进抽屉**：点「诉讼图」「版式」……旁边才滑出它的抽屉，再点一下或点右上角收起；打开编辑器时抽屉是收着的。
- **右栏只在选中卡片时出现**；没选中时，地方全给页面。
- **页面条搬进侧栏**，竖着排，点一页切过去，拖动调整页序。
- **顶栏只留五样**：课件标题、这一页的检查（「可以导出」或「几处要改 · 几处请核」，点开看明细）、撤销 / 重做、「⋯」、导出。
  网格、整理、换排法、课件风格、快捷键收进「⋯」；「AI 生成」按钮换成页面下方的输入框（Ctrl / ⌘ + 回车发出）。
- 缩放按钮平时淡一些，鼠标移到页面上再显出来；分组标题去掉了横线。

**视觉：**
- **界面不再用深红。** 原来深红是界面主色（Logo、导出按钮、选中态、图标）；现在界面只有中性灰，主按钮黑底白字，
  选中项浅灰底。奇川风的深红只留在课件页面这份**内容**里。
- 白主区、浅灰侧栏、栏与栏之间一条细线；圆角 8–10px；品牌字标「新诉讼可视化」用宋体，其余 13px 无衬线；不靠加粗分层。
- **深色模式**：跟随系统；侧栏右下角的月亮可以手动切换（只记在本机浏览器里，不进课件）。页面在深色模式下仍是白纸，
  选框、吸附线、手柄用近黑，看得见。

**在 AI 助手（Agent）里打开编辑器（`studio.py --detach` / `--stop`）：**
- 实测：Agent 的命令有时限（常见 2–10 分钟），到点或一轮结束会把它启动的进程一并清掉。原来 SKILL.md 让 AI 直接跑
  `studio.py`——前台跑、`&` 后台跑，编辑器都在几分钟后断掉，浏览器里页面还在，点什么都没反应。
- `--detach`：编辑器脱离 Agent 的进程组（Windows 上脱离控制台与作业对象）独立运行；先像浏览器那样连一下、认清开的是这套课件，
  才打印网址、返回 0。已经开着就直接给原网址，不再开第二个。`--stop` 只结束「那个网址上、开着这套课件」的进程。
- 打不开就明说（退出码 3）：服务没起来，或者命令跑在关了网络的沙箱里（Linux 上只剩回环口——那里连得上，沙箱外的浏览器连不上）。
  给两条路：允许命令在沙箱外运行再开一次，或不开编辑器、改走脚本导出。
- `ai.py wait` 的默认等待从 900 秒改为 90 秒：900 秒超过多数 Agent 的命令时限，会被中途掐掉。没等到照旧退出码 4，再 wait 就是。
- 新增只读接口 `/api/ping`（课件目录与进程号），供上面认人；同样只认本机 Host。
- 不加 `--detach` 时与原来完全一样（用户自己在终端里开）。

**图表库：把 V6 的能力放出来（缪律师：V7 是给课件做图形图表的，V6 的一百多种场景在 V7 里没有体现）：**
- 侧栏第一位「图表库」：V6 场景库里现在就能画的 124 个法律场景（13 种画法），盖住画布的一整页；卡片是 V6 按课件风格
  真画出来的图，写场景名、要回答的问题、画法与适用场合。搜关键词，按场合、画法筛。同一画法交错排，漏斗排最后（备用画法）。
- 点「放进这一页」/「新建一页」：先放 V6 的示例数据（`sample` 记号），右栏 AI 输入框写好请求；示例数据导出前一定被拦下，
  换成用户的数据后记号自动去掉。AI 的上下文带上这个场景（要回答的问题、特有守卫）。
- 入口改名：选图 → 诉讼图（V1–V5），排法 → 版式，说明 → 卡片。「V6 内置示例」并进图表库。
- 第二轮（缪律师：要像给法律人解决真问题的工具）：图表库从律师要说明的事出发——标题问「这一页，想让人看懂什么？」，
  先按「由什么构成、有多少、钱怎么算、流向哪里、风险在哪、争什么……」分，再按场合、画法筛；卡片以律师的问题为标题，
  下面是场景名、领域与画法、「比如：」一句法律例子、「核对：」这一类图特有的核对规则。缩略图按整页幻灯片的比例画（16:9），
  字与图的比例和放进课件时一样。

**示意图重画（缪律师：灰方块拼的线框太丑、小图标和字挤在一起）：**
- 版式、诉讼图场景、整套课件：缩略图画成一页真的 16:9 小页面——标题一道深色、柱图、时间轴、关系图、要点各是各的样子，
  重音色只点一处。卡片：画成样张（「+56%」、法条、裁判要旨、证据清单……），不再是图标加一行字。抽屉加宽到 340px。

**宋体标题不再伪加粗（缪律师：字比方正小标宋粗一大坨）：**
- 原因：标题字体排第一的是方正小标宋（本身就是重的标题字、没有粗体字面），程序再给 700 字重（浏览器、PowerPoint 伪加粗），
  另加 0.3 同色描边。现在宋体标题用小标宋本来的字重，不加粗、不描边；没装小标宋的电脑依次落到华文中宋、思源宋体 SemiBold。
- V1–V6 的图放进课件页时，图里的宋体加粗标题同样改（旧图也照改）；黑体的粗字（一句话结论、编号）不动；本来是常规字重的宋体（金句、要旨正文）不动。
- 导出 PPT：编辑器认出本机装了方正小标宋，标题就用它、不加粗；没装照旧宋体加粗（在别人电脑上不变样）。命令行 `--title-face`。
  V1 的 `export_pptx` 加了可选参数 `title_face`，不给时与原来逐字节相同。
- 成品账更新：奇川风 12 页变了，逐页核对过——把旧页按新规则改写后与新页完全一致，别的一个字节没变；歸藏风 13 页不变。

**AI 请求：做完就停（缪律师：让 AI 再来一版，反反复复搞了半天没有结论）：**
- 原来 SKILL.md 与上下文都写「做完回到 wait 等下一条」（上一轮还加了「没等到就再 wait」），AI 一直空等、不收尾。
  现在处理完待办就在对话里说明并结束这一轮；`wait` 等不到时也明说「不要再 wait」。
- 编辑器看得出 AI 是否在等（`ai/listening.json`）：在等显示「AI 马上开始」，不在等显示「回对话里说『处理课件请求』」。

**右边交给 AI 时页面乱跳（缪律师：会刷新或者弹出）：**
- AI 重复执行「打开编辑器」时，原来每次都替用户再开一个浏览器标签页；现在已开着就只给网址，不再弹。
- 正在打字（AI 输入框、标题）时 AI 改了课件，原来右栏整块重画、打了一半的字就没了；现在等打完再刷新。
  正在打字时顶栏的「这一页检查」也照常更新（原来不更新）。

**没动的：** 网格、吸附、推挤、读图、合并保存的逻辑一行没改；导出只多了「标题字」一项（不给时与原来逐字节相同）；
AI 请求只改了收尾的说法与「是否在等」的提示，交回结果的校验一行没改；被挪走的按钮元素都还在（藏起来，快捷键与各处调用照旧）。
回归 725 项全过（新增 37 项；新增的检查都故意改坏代码试过，能报错）。

## 0.8.4 · 随套件 v2.4.0

**0.8.4 续 · 编辑器更顺手（先量、再改；学案图的画布）：**

- **改：竖版的法律关系图放进课件页字太小、被拦下时，指出能走通的路**：回 V3 加 `--shape wide` 出横版（V3 新增的选项）。
  演示时用 6 个模块的关系图撞到：V3 默认排成单列竖条，放进 12×5 的图卡字只剩 5 像素左右。别的图照旧只提示切片、拉大。
  AI 调 V3 出图时的说明里也写上 `--shape wide`。
- **改：编辑器不再一改就重拉整套。** 实测改一个字，13 页的课件发 15 个请求、65 页的发 67 个（每张缩略图都重拉，
  整套检查也重拼一遍）；拖一张卡 0.6–1.4 秒才安静下来。现在每页画面按「第几页 + 页 id + 版本 + 整套设置」记住，
  只取、只查变了的页：改一个字 1–3 个请求，拖卡 0.25–0.35 秒，翻页 0.2–0.4 秒 → 0.03–0.09 秒（65 页同样）。
  只在课件存好之后去取画面——存的路上取，会把改之前的样子记成新的（实测撞到过，已改）。
  另用浏览器逐张核过：改字、换风格、复制页、删页、撤销、AI 在别处改、翻页之后，每张缩略图、主画面、每页检查结果都与本机服务现拼的逐字相同。
- **新：缩放与平移。** 右下角「− 60% +」；按住 Ctrl / ⌘ 滚轮以光标为中心缩放（触控板捏合也行）；Ctrl+= / Ctrl+- / Ctrl+0。
  下限是适应窗口，上限是实际像素的 2 倍；放大后在中间这一块里滚动，不把整个界面撑高。1366×768 的笔记本上一页只有约 760 像素宽，
  细调卡片时可以放大；放大时拖卡、吸格照常。不放大时界面与原来逐像素相同（1280、1366、1440、1920 四种宽度核过）。
- **改：课件或律所风格是更新版本写的**（例如同事用新版做的课件，您这里还是旧版）：原来只说「schema 要是 deck@2」，
  像是文件坏了；现在明说「请把插件升级到最新版再打开（课件本身没有坏）」。学自案图。
- **新：悬停看出处（学自案图）。** 鼠标停在图里的事件、柱子上，浮出它出自哪里；选中图卡，右侧「出处」列出全部。
  只读原模块写好的出处、不编：V2 时间轴出图时旁边那份 `<名>-trace.json`（和图一起放进 assets/：事项、材料、第几句、原文摘录）；
  V6 用逐件记录（dataset + view）出的图，每一项来自哪几条记录、编号（行号与 V6 一样从 0 数）。其余的图没有逐项出处，不显示。
  不打开「写进备注」时，导出的 PPTX 逐字节不变。
- **新：V3 关系图也能悬停看出处。** V3 出图时给每个主体、每条关系标上编号（`data-ref`，不改画面），并在图旁边写同样的 `-trace.json`；V7 按编号对上，原有的元素键不变（已经放好的读图编号不受影响）。出处照录 relations.json 的 source；**没写出处的，悬停时明说「没写」**（讲之前最该补的就是这几条），演讲者备注里不写它们。
- 修：图旁边的出处记录（`-trace.json`）原来会被当成一张空图表列进「已有的图」。
- 修：在编辑器里把出处记录拖进来（或「选文件」）原来被当成写坏的图表说明拒掉，只能手动拷进 assets/。现在和图一起拖进来就行，拖进来后每页立刻重查，鼠标停在图上就看得到。
- **新（可选）：出处写进演讲者备注。** 编辑器「导出」里打开「出处写进演讲者备注」，或 `build.py 课件 --notes`：
  有出处的页，备注里逐条写「事项：材料、第几句「原文」」或「类目：逐件记录几条、编号」；讲课时演示者视图里看得到，观众看不到。
  备注母版、备注页、关系与内容类型照 PowerPoint 自己存出来的样子写，导出后回读核过；python-pptx 与 LibreOffice 都读得出备注。
  **不打开就一个字节都不加**（与原来逐字节相同）。作者用 PowerPoint 打开样张核过：不弹修复提示，备注里出处齐全。
- 回归 669 → 686，新增的每一项都先在旧代码上确认会失败（「不编出处」那一项是守卫：原来本就不显示出处）。

**0.8.4 · 实跑 AI 协作那条路（编辑器 ↔ 对话里的 AI ↔ 命令行），见 ADR 0005：**

- **修：AI 交回的结果「改不到没有为止」。** 交回的页拼出来还有要改的（实测：编了一个推不出的大数字 +60%），
  原来照样写进课件、请求算「做好了」；AI 改对了再交被拒（「已经是 done」），SKILL.md 写的循环做不到。
  现在写进去让用户看见，请求留在「正在做」并写明还有几处要改；对同一个请求再交，加页类换掉上次加的那几页，不越加越多；
  改不了的（缺用户的原文）用 `ai.py … done --note` 收尾。
- **修：几方同时写，请求会丢、文件会坏。** 暂存文件名原来是固定的：实测四个进程各记 25 条请求只剩 29 条，
  有进程读到空文件崩掉，还把请求文件写成两份 JSON 首尾相接（编辑器再也读不了）。现在课件文件夹一把系统文件锁、
  暂存文件各用各的（`scripts/safewrite.py`，只用标准库，锁文件从不删除）；编辑器保存、AI 交回、记请求都持锁。
- 改：给 AI 的请求上下文自带 `answer`：这一类请求交回什么，以及照抄就能跑的 `take / apply / fail` 命令（真实路径）；
  出图请求另给那个模块 SKILL.md 的路径。读上下文的模型不必回头翻 SKILL.md。
- 改：`build.py --new` 打印下一步（打开编辑器、逐页检查）的命令，脚本写真实路径。
- 修：导出被拦时印成「未导出：有几页还没准备好，未导出：」，现在只说一次。
- 修：编辑器窄栏里请求旁的「取消」按钮折成两行竖排。
- 回归 663 → 669，新增的每一项都先在旧代码上确认会失败；示例课件导出的 PPTX 逐字节不变。

- 测试：编辑器按页合并的 JS 对照改为写成文件再交给 node（原来走 `node -e`，命令行里的中文在 GBK 区域设置下被改坏）；子进程输出一律按 UTF-8 读。课件产物不变。

- SKILL.md 加「运行与交付须知」：课件文件夹建在用户的工作目录，不建进技能目录。

- 课件文件夹里用记事本另存过的 deck.json、图表说明（UTF-8 带 BOM）照常读；实测导出的 PPTX 与不带 BOM 时逐字节相同。

- V6 奇川风的注释色由 #9CA3AF 改为 #6B7280（白纸上对比度 2.5 → 4.8）。示例课件奇川风 6 页随之变化：
  逐页核过，只有页脚、图表来源行与刻度的这一处颜色不同，其余逐字相同；成品账已 `--update`。
