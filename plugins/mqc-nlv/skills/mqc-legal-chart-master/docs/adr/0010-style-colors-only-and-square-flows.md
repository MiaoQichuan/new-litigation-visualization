# 0010 颜色只用风格原色；流带一律直角

## 背景

1. 0.7.0 学 lieflat-charts-custom 的「按气质选配色」，开放了九个强调色预设（朱砂、胭脂、赭石、古铜、藏青、
   黛蓝、石青、墨绿、绛紫）与任意 #RRGGBB。外部测试按功能把九个预设都跑了一遍，作者在结果里看到绿色、青色的图：
   这与奇川风、歸藏风都不是一回事。
2. 桑基、汇入图的流带在奇川风里按「填充形状都是贝塞尔小圆角」磨了圆角。作者看了成图后定：流带是长条，
   与两侧竖条一样，角是直角，图形才统一。

## 决定

1. **颜色只用风格原色**：奇川风的重音只有 #991B1B，歸藏风只有 #002FA7。取消预设与自选色值；说明里的 `accent`、
   命令行的 `--accent` 一律拒并说明。旧档案里留下的强调色不用、照常出图，交付清单里说明（档案是默认值，不是指令）。
   这修订了 ADR 0007 里「强调色预设」一条，以及会话初期「给用户更多颜色选择」的做法。
2. **流带一律直角**：桑基、汇入图的流带在两种风格下都不磨圆；G9 把流带与竖条、中位数线一起列为长条，磨圆即拦。
3. 两项都记入防改差账本：判定账新增 4 条「写了强调色就拒」；改坏验证新增「流带被磨圆」两条；成品账里 26 份
   桑基 / 汇入图成品带理由更新，其余 114 份不变。

## 否掉的替代方案

- **只删绿、青、紫，留深红一系的预设**：仍会出现与奇川风原色不同的红，作者要的是「不能出现跟风格不同的颜色」。
- **档案里有强调色就报错**：会让已有的档案突然不能用；不用它、说一声，图照样是风格原色。
