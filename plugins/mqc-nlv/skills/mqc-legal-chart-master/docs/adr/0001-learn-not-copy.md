# 0001 学 lieflat-charts 的方法，不搬它的代码

## 背景

lieflat-charts 是一套做得很好的数据图 skill：按数据形状选图、面积开方、不断轴、卡片四件套
（结论标题、口径副标题、图、来源行）、单位分解（1 点 = 1 件）。本模块的思路大量来自它。

## 决定

学方法与判据，用本仓库的内核重新实现，不复制它的模板与代码。

## 理由

- 它的许可证是 PolyForm Noncommercial 1.0.0（非商业），本仓库是 MIT。搬进来的代码会给整个
  仓库带上非商业限制。
- 技术路线本来就不同：它出 HTML、依赖 ECharts / Chart.js 与在线字体；本仓库出确定性 SVG 与
  可编辑 PPTX，不联网，三种风格与 PPTX 导出都已经在 V1 里。

## 否掉的替代方案

- **直接内嵌它的 HTML 模板，再截图成 PNG。** 许可证冲突；而且截图丢掉了可编辑性，
  进不了 PPTX 原生对象。
- **改用 ECharts 渲染再转 SVG。** 引入第一个前端依赖，确定性与逐字节比对都保不住。
