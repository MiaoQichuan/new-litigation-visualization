# 0008 点阵用方块模块；V6 对 V7 的接口

## 背景

作者看了 0.7.0 的百点方阵后定了两件事：

1. 点阵不用小圆点，改成「正方形加贝塞尔小圆角」的方块，圆角可以比大形状的角大一点，但整体要像正方形，
   像一块块模块拼成的点阵；歸藏风全部是直角正方形。
2. V6 的设计要考虑与 V7（法律课件大师）衔接：有些设计 V7 那边要能用到，V7 也要能用 V6 的部分。

## 决定

1. **方块模块**（`Fig.module`）：边长 = 格宽 × 0.74；奇川风圆角 = 边长 × 0.22，歸藏风为 0。
   用于百点方阵的每一格与图例色块。逐件分布、哑铃上的点表示数轴上的位置，不是点阵，仍是圆点。
   守卫 G9 新增：点阵必须是方块；奇川风圆角在边长的 15%–30% 之间，歸藏风必须直角。
   这个比例写进设计令牌，V7 的小卡片、角标、拼块用同一条规则，「方块模块」就是两边共用的视觉语言。
2. **设计令牌** `design/tokens.json`，由代码生成，测试核一致。V7 只从这里取颜色、圆角、字号。
3. **版位**与 **fit**：V6 回答「这份说明放进 V7 的某个格子放不放得下」，放不下就不放，不缩小硬塞。
4. **模块清单**：V7 存说明 JSON 和渲染参数，不存图片；换版位、换风格时重新渲染、重新过守卫。

## 否掉的替代方案

- **V7 直接用 V6 的 SVG/PPTX 缩放排版。** 缩放会让字号跌破下限、圆角跟着变胖、比例尺失真，
  守卫也就形同虚设。重新渲染只多几十毫秒。
- **方块圆角沿用大形状的 5px。** 一格方块边长只有 10–40px，5px 在小格上忽大忽小；按边长比例才在任何
  画布上都是同一个样子。
- **令牌手写一份给 V7。** 两份会漂移。由代码生成、测试核对，才只有一个来源。
