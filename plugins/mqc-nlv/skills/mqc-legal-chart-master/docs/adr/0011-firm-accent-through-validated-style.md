# 0011 律所风格：重音可以换成律所主色，只走经校验的那一条路

## 背景

ADR 0010 收回了自选强调色：随手配色出现过绿、青、紫的图，与两种风格都不是一回事。
0.9.5 起法律课件大师（V7）开放「律所风格」：读律所自己的 PPT 模板，生成律所风格文件。作者定的：
课件用律所风格时，图表重音也要跟着换成律所主色，否则律所的紫色版面上会出现奇川风的深红图。

## 决定

1. 只开一个口子：`firm_palette({"name", "base", "accent"})`。重音换成律所主色；灰阶梯、几何、圆角、字重仍按基础风格。
2. 律所主色要过三道检查：格式是 #RRGGBB；饱和度不低于 0.2（不能是灰，否则和灰阶梯分不开）；
   在纸上当字、上面压白字，对比度都不低于 4.5。过不了就拒，并说清是哪一道。
3. ADR 0010 不变：命令行、说明、档案里随手写的强调色照旧拒。律所风格是「一家律所一种主色」，由模板读出、
   人核对过，不是「这张图想换个颜色」。
4. 律所风格可另给图标题字体 `title_font`（serif / sans，只此两种）：律所课件用粗黑体标题时，图标题跟着用无衬线、字重 700。
5. 守卫照旧逐色核对：白名单 = 基础风格白名单 − 基础重音 + 律所主色。

## 后果

- 律所课件里的图和版面同色，仍然只有一处重音。
- V6 单独出图时不受影响；律所风格只在调用方（V7）显式传入时生效。
