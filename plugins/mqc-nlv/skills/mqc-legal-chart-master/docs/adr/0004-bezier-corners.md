# 0004 奇川风的尖角改成贝塞尔小圆角；歸藏风保持直角

## 背景

0.1.0 沿用「量是尺」：数据柱一律直角，理由与 V1 的期间条（r = 0）相同。作者看过成品后定为：
柱、扇区、节点、流带，凡是矩形、三角形、多边形的尖角，全部改成一点点贝塞尔小圆角，这才是
奇川风。箭头除外。

## 决定

- 所有填充形状经 `corners.rounded_d` 生成：每个转角大于 12° 的顶点，在两条边上各退回一小段，
  用三次贝塞尔接起来；控制柄按圆弧近似取 h = 4/3 · tan(θ/4) · ρ，所以角是真正的圆角。
- 半径：整页幻灯片 5px，随画布缩放，不小于 3px；相邻边太短时自动收小，不会把形状磨坏。
- **只用于奇川风。** 歸藏风是瑞士风格，一律直角、平头；G9 在歸藏风下反过来拦圆角。
- 弧线采样点之间的微小折点（< 12°）不磨，玫瑰的外弧保持是圆弧。
- 奇川风的线段一律圆头。
- 守卫 G9 读产物：不许出现直角 `<rect>`，每个填充 path 的角都要由曲线接替，线头要圆。

## PPTX

V1 的导出器只认直线段。交付前由 `make.pptx_ready` 规整：原本是矩形的 path 还原成原生圆角矩形
（PowerPoint 里拖黄色控点还能调圆角）；其余形状把曲线细分成折线，圆角形状保留。SVG 交付物不动。

## 否掉的替代方案

- **SVG 用 `rx` 做圆角。** 那是椭圆弧，只能用在矩形上；扇区、流带照样是尖角，两套做法会不一致。
- **把圆角做大（8px 以上）。** 柱会变成胶囊，读起来像按钮；要的是「一点点」。

## 修订记录

- 0.2.0：半径 3px（最小 2px），两种风格都磨圆。
- 0.2.1：作者看过成品，定为半径加大一点点（5px，最小 3px）；歸藏风不要圆角。
- 0.3.1：细长条不磨圆。桑基与汇入图两侧的竖条、中位数竖线一律直角平头，颜色由近黑改为深灰。
  圆角在细长条上只剩两头的一点弧，读起来像毛边，不像设计。
- **改 V1 的导出器让它认曲线。** 共享内核的改动会波及五个模块，这一处在 V6 侧规整即可。
