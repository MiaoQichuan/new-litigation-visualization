# V6 → V7 接口

> V7 法律课件大师要把 V1–V6 的产物当作「磁吸模块」拼进课件，最终出 PPTX。
> 这份文件写清 V6 对 V7 承诺什么、V7 拿到后可以做什么、不可以做什么。

---

## 1. 一句话

**V7 收进课件的是说明 JSON，不是图片。** 一个 V6 模块 = 一份说明 + 一组渲染参数（风格、强调色、版位）。
要换位置、换大小、换风格，V7 用说明重新调 V6 渲染，守卫重新验一遍。所以图在课件里永远是从数据
算出来的：不会被拉伸、比例不会走样、圆角不会被放大成胖圆角。

## 2. 设计令牌 `design/tokens.json`

由 `scripts/module.py tokens` 从 `styles.py`、`spec.py`、画框字号生成；回归测试核对两边一致，
改了风格没重新生成会被拦下。V7 的页面元素（页面标题、页码、目录、卡片底、角标）只从这里取值：

| 令牌 | 内容 | V7 怎么用 |
| --- | --- | --- |
| `styles.<风格>.color` / `ladder` / `whitelist` | 纸色、墨色、灰阶、重音色 | 页面底色、正文与注释颜色；V7 页面上的颜色也不出白名单 |
| `styles.<风格>.corner` | 大形状的圆角（整页 5px，随画布缩放，不小于 3px）；方块模块圆角 = 边长 × 0.22；细长条与箭头不磨圆 | 卡片、标签、按钮、角标用同一套角。歸藏风全部直角 |
| `fonts` / `type_scale_px_at_1280x720` / `type_scale_rule` | 标题宋体（奇川风）或细黑（歸藏风），字号阶梯与缩放规则，下限 11px | V7 的页面标题与正文按同一阶梯，课件与图的字一样大小关系 |
| `accent_policy` | 只用风格原色（奇川风 #991B1B、歸藏风 #002FA7），不接受自选强调色 | 整套课件只在两种风格之间选，不另设颜色 |
| `canvases` / `slots` | 画布与版位 | 版式网格 |
| `charts` | 每种图的复杂度预算、能否批注 | V7 的模块面板据此提示 |

## 3. 版位

V7 的页面是 16:9（1280 × 720）。一个 V6 模块可以占：

| 版位 | 尺寸 | 说明 |
| --- | --- | --- |
| `full` 整页 | 1280 × 720 | 模块自带标题、口径、来源，一页就是一张图 |
| `two-thirds` 三分之二栏 | 816 × 600 | 另三分之一放 V7 的文本框或要点 |
| `half` 半栏 | 608 × 600 | 左右并排两个模块（例如一审结果 vs 二审结果） |
| `wide` 通栏矮条 | 1152 × 480 | 页面标题之下的一条 |

`python3 scripts/module.py fit 说明.json` 逐个版位、逐个风格试渲染并过守卫，告诉 V7 哪些格子能放。
**放不下就不放**，V7 不许把整页的图缩小塞进半栏——缩小会让字掉到 11px 以下，守卫本来就会拦。
`make.py --canvas` 也认这几个版位名。

## 4. 模块清单 `<名>.module.json`

`make.py 说明.json --formats svg,pptx,module` 另写一份清单：

```json
{
  "schema": "mqc-nlv/module@1",
  "kind": "chart",
  "producer": {"skill": "V6 mqc-legal-chart-master", "version": "0.8.0"},
  "chart": "hbar",
  "spec": { …原样的说明 JSON… },
  "render": {"style": "奇川风", "accent": "#991B1B", "accent_in": null, "w": 1280, "h": 720, "profile": null},
  "slots": {"full": true, "two-thirds": true, "half": true, "wide": true},
  "a11y": {"title": "…", "desc": "…"},
  "provenance": {"scope": "…", "n": 1330, "source": "…"},
  "emphasis": "loan",
  "annotations": [ … ],
  "review": [ …要人工核的项… ],
  "files": ["图名.svg", "图名.pptx"]
}
```

## 5. V7 可以做 / 不可以做

可以：

- 换版位、换风格（整套课件统一换），然后重新渲染；颜色跟着风格走，不单独换
- 把 `a11y`、`provenance` 用在讲稿、备注页、参考文献页；
- 把 `review` 汇总成整套课件的「请核清单」。

不可以：

- 拉伸、裁切、重新着色 SVG 或 PPTX 里的形状；
- 在 V6 模块上叠第二处重音，或在页面上再加一层与数据相关的数字（要加就写进说明，让 V6 核）；
- 绕过守卫：重新渲染守卫不过，模块就不能进这一页。

## 6. 下一步（V7 开工时一起做）

- **无框模式**：模块放进 V7 页面时，标题由 V7 的页面标题承担，模块只画图身，来源行合并到页脚。
  标题的数字核对（G8 / 标题规矩）要随标题一起搬到 V7 的页面层。
- **PPTX 组合**：多个模块的 PPTX 形状合进同一页，各自成组，组名就是模块 id。
- V1–V5 不改（作者定的）：V7 要收它们的产物时，由 V7 读它们现有的输出（SVG / PPTX / 说明 JSON），不要求 V1–V5 另出清单。
