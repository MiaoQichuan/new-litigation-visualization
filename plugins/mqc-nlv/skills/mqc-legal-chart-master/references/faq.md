# 法律图表大师 · 常见问题、报错对照与限制

遇到问题先看这一份：三步上手、常见误用、报错怎么改、术语速查、已知限制都在这里。

## 一、三步上手

    python3 <本技能目录>/scripts/make.py --check                                    # ① 看本机能出什么
    python3 <本技能目录>/scripts/make.py <本技能目录>/examples/waffle-outcomes.json -o 图/判决结果   # ② 出一张示例图
    python3 <本技能目录>/scripts/find.py 审理周期                                    # ③ 按法律场景找画法

在 AI 助手里直接说：「用法律图表大师，把【材料】做成【这页要说明什么】，在【场合】给【谁】看，重点标【哪一处】。」
材料可以是一组现成数字、一张逐件登记表（CSV / Excel）、或一批判决书；助手写好图表说明 JSON 后出图。
`examples/` 里有十九份示例，每种图至少一份，照着改最快。

## 二、常见误用（反模式）

| 误用 | 会发生什么 | 该怎么做 |
| --- | --- | --- |
| 把百分比、合计写进 data | 守卫按件数核对，口径会乱 | data 只写原始件数，占比由脚本算 |
| 标题写数据里推不出的数（「增长约六成」） | 拒绝出图 | 按报错改；推不出就不写数 |
| 逐件记录自己先数好再写 | 数错一件守卫拦不住 | 用 dataset + view，让脚本数 |
| 被拒后换图种、换画布去绕 | 绕不过去，且离题 | 报错指名哪一条就改哪一条 |
| 改写类目名（「民间借贷纠纷」→「借贷」） | 与材料对不上 | 类目名只许删减，不许改写 |
| 一张图标两处重音 | 等于没标 | 重音只给标题里说的那件事 |
| 自选强调色（`accent`、`--accent`） | 拒绝出图 | 换风格：奇川风（深红）或歸藏风（克莱因蓝） |
| 拿它做胜诉率、预测 | 统计推断不在范围内 | 只呈现计数与派生数，并写明 n 与口径 |
| 退出码不是 0 却说「已生成」 | 交付了不存在的文件 | 以「文件」行与退出码为准 |

## 三、报错对照

所有报错都以「未出图：」开头，说清哪一处、怎么改，不甩 Python 堆栈。

| 您会看到 | 意思 | 怎么办 |
| --- | --- | --- |
| `要给一份说明 JSON` | 没给文件 | `make.py 说明.json -o 图/名字` |
| `找不到图表说明 …` | 路径打错 | 核对路径；中文路径与空格都可以，记得加引号 |
| `JSON 写坏了：第 X 行第 Y 列` | 多了逗号、中文引号、少括号 | 按行列号改 |
| `缺 n：样本量` | 没写样本量 | 写 `n`，并与数据对账 |
| `n 写的是 X，按数据算是 Y` | n 与各类目之和不一致 | 改 n 或补齐数据，两者必须一致 |
| `缺 source：来源行` / `缺 scope：口径` | 没写来源或口径 | 写明数据来自哪里、什么法院、什么时间段 |
| `标题里的百分比 … 由数据推不出来` | 标题编了数 | 改成原值、n 或由数据算得的数 |
| `chart 要是 bar / hbar / … 之一` | 图种拼错或不支持 | 用列出的十七种之一；拿不准读 `references/catalog.md` |
| `不认识的字段：…（拼错了？）` | 字段名拼错 | 对照 `schemas/` 与示例 |
| `emphasis 指向 '…'，数据里没有这个 id` | 重音指错 | 用报错列出的可选 id |
| `V6 不换强调色` | 写了 accent | 删掉，改用 `--style` |
| `请核　…`（不是错误） | 约数、条文编号、案号等要人工过目 | 原样转告用户确认，不能当作已核 |
| 退出码 3、一个文件都没写 | 要的 pptx / module 有一样没做成 | 按上面一行的原因修；PNG 缺工具只会跳过，不会退出码 3 |
| `版本过旧`（`--check` 或启动时） | 旁边的 V1 内核是旧版 | 装单独安装包（`vendor/` 自带内核） |

## 四、术语速查

| 术语 | 一句话解释 |
| --- | --- |
| 图表说明 | 一份 JSON：图种、标题、口径、来源、n、数据；模型只写这一份 |
| n | 样本量，必须与数据之和对得上 |
| 口径（scope） | 哪个法院、什么案件、什么时间段；公开文书不是全量，不写就是误导 |
| 重音（emphasis） | 一图只标一处，给标题里说的那件事 |
| 守卫 | 出图后从成品 SVG 回读几何与文字，不成比例、字太小、文字互压就不交付 |
| 请核 | 脚本核不了分寸的项（约数、条文号），交给人确认 |
| dataset + view | 逐件登记表原样抄进 dataset，在 view 里写怎么分组，由脚本数 |
| 类案编码 | 一批判决 → 编码表 → 一组图（样本筛选、构成、地域、层级、年份、金额） |

## 五、已知限制

- 有正有负、要并排比较的数据（正负对比条）暂不支持，会明说。
- 标题里的中文约数（「四成」「过半」）按区间核对，分寸请人工过一眼。
- 公开裁判文书不是全量，图上会写明样本量与口径。
- 不做案件经过的时间轴、法律关系图、流程图，也不做统计推断与预测。
- 类案编码读判决书文件要 V4 的读取层（单独安装包已随包附带）；读 .xlsx 清单要 openpyxl，没有就另存 .csv。

## 六、隐私与合规

- 纯本地运行：出图只用 Python 标准库，**不联网、不调用任何外部 API**。
- 只读您给的材料，产物只写到您指定的目录；不收集、不上传任何数据。
- 判决书里的当事人信息不会替您脱敏；对外发布前请自行处理。
