# 图种目录：数据形状 → 图种

**先判数据长什么样，再选图。** 用户说的是人话（「把这几年收案画一下」），不说图名。
下表左列是形状，右列是唯一的选择；同一形状不给两个候选，避免每次挑得不一样。

| 数据形状 | 法律场景举例 | 图种 | 上限 |
| --- | --- | --- | --- |
| 少数类目比大小，类目名短（年份、程序名） | 历年收案量、各庭结案数 | `bar` 竖柱 | 14 根；名放不下自动换横条 |
| 类目比大小或排名，类目名长 | 案由分布、各法院收案、常见争点 | `hbar` 横条 | 16 条 |
| 100% 构成，2–4 类 | 判决结果（支持 / 部分支持 / 驳回）、调撤率 | `waffle` 百点方阵 | 4 类；能摊回件数就按件数画 |
| 构成，3–12 类，用于讲课的展示页 | 案由构成、罪名构成 | `rose` 南丁格尔玫瑰 | 12 类；面积编码 |
| 每一项有两个值要对照 | 诉请与判赔、一审与二审刑期、约定利率与支持利率 | `dumbbell` 哑铃 | 12 行 |
| 一件一个连续值，看分布与离群 | 审理天数、判赔金额、刑期 | `strip` 逐件分布 | 6 组，每组 400 件；可画审限等阈值线 |
| 多段去向 | 一审 → 上诉 → 维持 / 改判 / 发回；立案 → 调解 / 判决 | `sankey` 桑基 | 2–4 段；中间节点进出相等 |
| 几个来源汇入几个去处，来去交叉 | 资金流向（付款账户 → 收款账户）、案件来源 → 承办部门、证据 → 待证事实的份数 | `ribbon` 汇入图 | 两侧各 2–8 个 |
| 从一个数一级级加减到另一个数 | 诉请怎样变成判赔（各项抵扣、调减）、样本怎样筛到 n、清偿率怎样算出来 | `waterfall` 逐级加减 | 12 级；中间各级可正可负，累计与终点不能为负 |
| 两个类目维度交叉，每格一个数 | 历年 × 案由的收案、各法院 × 裁判结果的件数 | `matrix` 气泡矩阵 | 12 行 × 14 列、合计 120 格；面积编码，自带行列合计 |
| 几个项目各一个长度，另有一个量要一起看 | 各类案件平均审理周数与收案量、各分项工期与损失 | `fan` 发射扇 | 12 根辐条；辐条上的点数 = 主数值，圆面积 = 第二个量；由长到短排 |
| 一串条目分属几个主题，要看「集中在哪」 | 争议焦点归类、诉请归类、证据归入待证事实 | `converge` 放射汇聚 | 2–8 个主题、4–60 条；枢纽面积 = 条目数 |
| 几个类目各有一个件数，要一眼看出「谁最多」，又想数得出来 | 类案判决里各争点、违约事由出现的件数 | `cascade` 点阵阶梯 | 3–16 列，一列最多 30 格；一格 = per |
| 几部法律（司法解释、文件）各自何年通过、修改、废止 | 公司法与民诉法的历次修改；民法典施行后废止的单行法 | `lineage` 法条沿革 | 2–10 行；横向为年份 |
| 每一项是一段区间（最低到最高、下限到上限） | 各地判赔区间与中位数、量刑区间、置信区间 | `interval` 区间胶囊 | 12 条；纵轴含 0，可为负 |
| 一组构成，每一类另有一个量要一起看 | 各类案件的占比与平均审理天数、标的额占比与平均标的 | `radpie` 双读饼 | 2–8 个扇区；角度 = 占比，长度 = 第二个量 |
| 一级比一级少的逐级筛减（备用；优先用逐级加减，样本筛选也用它） | 执行立案 → 查控到财产 → 全部到位 | `funnel` 漏斗 | 2–8 级；只减不增 |

## 选法上的几条

- **构成优先百点方阵。** 百点方阵比饼图难被质疑：100 份判决画成 100 个点，数得出来。
  只有类目多于 4 个、又是讲课的展示页时，才用玫瑰。
- **玫瑰不是饼图的升级版。** 它按面积读数，适合「谁最大」一眼看出来的场合；要读准确数值，
  用横条。
- **哑铃只用于「同一件事的两个值」。** 两个不同口径的数放在一行，是在暗示它们可比。
- **桑基与汇入图怎么分。** 一段接一段往下走（一审 → 上诉 → 结果）用桑基；只有「从哪来、到哪去」
  两列、而且来去交叉才是重点（谁的钱进了谁的口袋）用汇入图。汇入图的流带半透明，交叉处叠深，
  读者才看得出几股钱在哪里汇合。
- **逐级加减只画「一个数怎样变成另一个数」。** 起点、每一级、终点都照抄材料；最后一级必须等于终点，
  对不上就是漏了一级。不同项目之间的正负对比（各业务线同比增减）不是逐级加减，见下表。
- **漏斗只画「只减不增」。** 每一级都是上一级的子集（查控到财产的案件都在立案执行里）；某一级比上一级多，
  说明口径不是同一批案件，换逐级加减或分两张图。
- **气泡矩阵是「年鉴」，不是热力图。** 读的是哪一格大、哪一行在长；要精确比较两个数，用竖柱或哑铃。
  当年数据不全的一行，用 `status: "dashed"` 画虚线圈，并在 `dashed_label` 里写明，不要让读者把半年当一年比。
- **发射扇是讲课的展示页。** 辐条上的点数按数值算，圆按面积算；只为好看而用、两个量之间没有关系时，用横条。
- **放射汇聚读的是「集中在哪」。** 归类标准要事先写明；条目名太长或太多放不下时去掉条目名只画点，
  名单附在交付清单里，不要缩小字号硬塞。
- **点阵阶梯数得出来。** 一格就是 per 件，格数由脚本四舍五入算出；要精确读数看列顶的数字。
  一份判决可以涉及几项争点时，件数之和不等于 n，口径里要写明。
- **法条沿革只画年份。** 年份照抄公布文本；同一年改了两次只写一次并在来源注明。横向是年份的比例尺，
  读者可以看出哪部法律改得勤、哪几部同年废止。
- **区间胶囊不是哑铃。** 哑铃是同一件事的两个值（诉请与判赔），区间胶囊是一批数的范围（最低到最高）；
  区间来自类案时，不要画成对结果的承诺。
- **双读饼只在两个量都要看时用。** 只看构成用百点方阵或玫瑰；第二个量与占比无关时，分开画两张横条更准。
- **逐件分布不聚合。** 每个点是一件真实案件；中位数由脚本算出画成竖线，阈值线（例如普通程序
  审限六个月）是规定，不是数据。

## 首批不做、以后补的

| 形状 | 计划图种 | 现在怎么办 |
| --- | --- | --- |
| 各项之间有正有负、要并排比（各业务线同比增减） | 正负条 | 明说不支持，不硬画；若其实是「一个数一级级加减成另一个数」，用逐级加减 |
| 多系列随时间变化 | 细线折线 | 竖柱只画一个系列 |
| 单个比例 | 刻度进度 | 写在标题里，不单独成图 |
