# 法律图表场景库

**场景可以无限扩，画法慢慢长。**

- `recipes.txt`　源文件。一行一个场景：领域、画法、意图、场景、名称、要回答的问题、法律例子、特有守卫。
  加场景只需加一行，不写代码。
- `taxonomy.json`　四个索引维度的登记表：领域、场景、意图、画法。
- `index.json`　由 `scripts/build_library.py` 生成，供检索脚本读。**不要手改。**

## 四个索引维度

| 维度 | 回答 | 例 |
| --- | --- | --- |
| 领域 | 哪个业务方向 | 破产重整、证券、劳动、刑事、数据合规、法律 AI…… |
| 场景 | 在什么场合讲 | 案例复盘、类案研究、新法解读、客户汇报、交易汇报、学术研究…… |
| 意图 | 这页想表达什么 | 发生了什么、钱怎么算、流向哪里、什么决定结果、进行到哪…… |
| 画法 | 用哪种图形画 | 逐级加减、点阵矩阵、汇入图、时间轴……（每种对应一个渲染器） |

画法另有一个**气质**标签：严谨（steady）或灵动（lively）。同一个场景常常两种都合适：
给法官看用百点方阵，给公众讲用一百个小人。

每个场景必须落在四个维度上，构建脚本逐行校验。

## 怎么用

```
python3 scripts/find.py 破产 清偿            按关键词找
python3 scripts/find.py --scene client --ready   某场景下现在就能画的
python3 scripts/find.py --show BKR-01        看一条的全部字段
python3 scripts/find.py --forms              各画法被多少场景用到
```

## 开发顺序不靠拍脑袋

`find.py --forms` 列出每种画法被多少个场景用到。待建的画法按这个数排队：用的人越多越先做。
