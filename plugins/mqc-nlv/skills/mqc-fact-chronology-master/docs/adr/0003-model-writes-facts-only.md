# ADR 0003 — 模型只写事实，原文、核对、算术交给脚本

**状态：** 已采纳

## 背景

三个测试案件在第三方 Agent 上试跑：每次都各写四五个抽取与拼装脚本（三案分别约 120KB、54KB、50KB 代码），
底稿里 41%–61% 是把原文重抄一遍，引语差一个空格就整份重写重跑，还截图自检。消耗大，也慢。

## 决策

- `ingest.py` 统一把材料抽成带行号的原文；模型读原文，在「事实.json」里只写事实，引语写行号。
- `make.py` 按行号取原文、改正空格与全半角差异、把跨行的引语接成一行、计算算式、拼底稿、检查、出页面。
- 出错只报到具体条目，模型只改那几条。

## 否掉的替代

- **让模型照录全文到底稿。** 输出量翻倍，且每抄一遍都可能抄错。
- **引语按相似度模糊匹配。** 会把不是原话的东西放进「」，违背照录。现在只容忍空格、全半角与排版折行三种差别。
- **让模型自己算加减乘除。** 模型心算不可靠；算式交脚本，对不上的进待审。

## 后果

用 03 号测试案件实测：模型要写的内容约为原来的 30%。
