# ADR 0002 — 只还原经过，不下结论

**状态：** 已采纳

## 决策

- 一件事一个事实，各份材料的说法都挂在它下面；日期、金额不一致照实并列，页面画冲突带、列待审，由律师选。
- 事实标题与叙述用中立措辞；评价性的话只能出现在「」照录的引语里。诉讼请求与主张单放，不当作事实。
- 事实之间的联系只连材料里写明的指向，不推断因果。
- 不设「一句话结论」。

## 否掉的替代

- **让模型先选一个最可信的日期。** 一个被选过的日期会被当成事实用，律师看不到另一份材料的写法。
- **按常理补全缺年份、相对日期。** 推断可以做，但必须标「推断」并写依据，交律师确认；不能静默补。

## 执行处

`scripts/check_base.py`（引语照录、日期原文照录、推断必须有依据、标题评价性字眼提醒）；页面的待审。
