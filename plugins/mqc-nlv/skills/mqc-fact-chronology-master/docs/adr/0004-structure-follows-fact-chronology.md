# ADR 0004 — 页面结构照 Fact chronology，升级只加在外面

**状态：** 已采纳

## 决策

页面的结构、时间线的记号语法（待审浅填充、已确认实心、有争议斜线圈、大致日期菱形、仅到月胶囊、起止粗条、
日期冲突小点、关键事实大圈）照 Anthropic Legal Artifacts 的 Fact chronology。新加的东西（对照矩阵、事实经过、
截至阶段、回放、金额冲突、推断日期、可疑日期、领域规则、算式核对）另放一处，不改原有记号的画法与含义。

## 否掉的替代

- **按自己的理解重画记号、重排页面。** 试过三栏布局的方向稿，结构一改，律师就认不出原来熟悉的东西，作废。

## 后果

颜色与控件可以改（灰阶底、深红标关键与选中、陶土色标冲突与待审、墨蓝只用于链接），结构与记号不改。
