# ADR 0001 — 它是交互看板，不是交付件

**状态：** 已采纳

## 背景

套件里已经有出交付件的模块：时间轴大师出可进卷宗的图，大事记表大师出 Word 交付版与 A4 简表。
案件看板解决的是另一件事：材料刚到手，律师要在一张会动的看板上把经过理清楚、把冲突裁决掉。

## 决策

页面是给办案团队用的工作台。导出只导页面上已有的东西（时间线图、事实表、大事记表与叙述、底稿、打印），
不做按受众定制的版式与风格。要交付件，去用时间轴大师、大事记表大师。

## 否掉的替代

- **在页面里做受众向导、多种 A4 风格。** 试做过：页面变重、运行变慢，且与时间轴大师、大事记表大师的职责重叠。

## 后果

页面保持一个不联网的单文件，约 0.6MB。
