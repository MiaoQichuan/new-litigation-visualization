# 更新记录

## 1.0.0 · 随套件 v3.1.0 开源首发

- 中文名「案件看板大师」（试跑时叫「事实时间线大师」）；英文名沿用 Fact chronology 的叫法。工作目录默认 `_案件看板/`，页面文件名 `案件名.案件看板.html`。
- 页面：时间线、对照矩阵、事实经过（大事记表与叙述）、待审、导出；结构照 Anthropic Legal Artifacts 的 Fact chronology，
  配色与控件取灰阶底、深红（991B1B）标关键与选中、陶土色标冲突与待审。
- 工作流：`ingest.py` 入库（PDF、Word、Excel、文本，增量）→ Agent 写「事实.json」（引语写行号）→ `make.py` 一条命令拼底稿、检查、出页面。
- 引语只差空格、全半角，或跨了排版折行，按原文自动改正；标题与叙述里的「」引语同样改正。
- 算式核对 `checks`：Agent 只写算式与材料所载结果，脚本计算，对不上的列入待审「数字对不上」。
- 判决书里的诉称、辩称、质证、拟证明段落按当事人的说法计入「仅有当事人陈述」；律师在页面上改过材料种类时以律师为准。
- 一卷多案、汇编文件拆分（漏行、重叠提醒）、副本与脱敏稿（`sameAs`，副本不得单独支撑事实）、背景材料（`background`）。
- 底稿与页面存回的格式相同，可反复读回；律师的裁决（`decisions`）、改动记录（`changes`）、页面里新加的待读材料（`pending`）随底稿保存。
- 修：材料没写出现阶段时整页事实被当作看不见（时间线空白）；现在默认为最早阶段。
- 示例 `examples/demo/` 的文件名改用 ASCII（`materials/`、`facts.json`）：Windows 自带解压遇到中文文件名会失败；回归测试复制到工作区时换回中文名，全流程仍在中文路径上跑。新增守卫：整个仓库的路径都必须是 ASCII（配反向验证）。
- 页面源码去掉六段早已被重写、从不运行的旧函数（含旧版新建入口里的「网盘」「交给 AI」字样）；去掉前后页面里在用的 154 个函数源码逐字核对一致。

开源之前的 0.1.0–0.3.2 为作者本地与三个测试案件的试跑版本，未单独发布。
