# ADR 0006 — 不引入 diagram-design 的无障碍契约与图种体系

**状态：** 已采纳（2026-08-19）

## 背景

研究过开源项目 `diagram-design`（也是一个 agent skill，28 种通用图种、以品牌视觉系统为核心、
产物是自包含 HTML）。结构与本项目惊人相似：`SKILL.md` + `references/` 按图种分文件 +
`scripts/` 放工具。它有 12 个 `verify-*.py`，每个配一个 `test-verify-*.py`，全部进 CI。

## 决策

**只学它的 ADR 制度**（本目录）。以下一律不学。

## 否掉的替代

- **SVG 无障碍契约**（`role="img"`、`title`/`desc`、`aria-labelledby` 顺序）。
  它有 `self_check.py` 专门验这个。不学的原因：**会改动每个渲染器的输出，动 447 项产物**，
  而这几十轮的纪律是「产物差异 0」。且对律师的实际收益低 —— 律师看图、打印、贴 Word，
  读屏软件几乎用不上。**哪天愿意接受一次产物变更，再单独做。**
- **把 4102 行的 `run_checks.py` 拆成十来个成对的 verify + test-verify。**
  方向是对的（能治「判据没人验」这个反复犯的错），但那是一次大重构，
  **重构期间产物与判据都可能被碰**，风险远大于收益。现在 rc=0、226 条判据在跑，不是坏状态。
- **28 种图种、品牌 token 与首次运行的风格问卷、HTML 自包含产物、动效、drawio 导入器。**
  换产品。本项目是时间轴专门 skill，作者定过「不是包罗万象地堆砌」；
  三档风格（白描 / 奇川 / 歸藏）是作者定的，不需要品牌抽取；
  主交付物是 SVG 且五种可编辑格式全部从它转出（pptx 可编辑是律师要的），换 HTML 会打断整条链。

## 值得记住的外部印证

它的 ADR 0005（标签几何靠检查器验，不靠评审）与本项目的方法论**独立得出同一结论**，
三句原话值得逐字记住：

- 九个已发布示例都是这样发出去的，**每一道现有门禁在它们上面全部通过** ——
  查颜色的、查 DOM 结构的，**两者都不读坐标**。缺陷只有把文件渲出来才看得见。
- **只活在文字里的规矩，就是会发出坏示例的规矩。**
- 检查器带对抗性测试，**两个极性都要覆盖** —— 该报的必须报，合法的必须不报。

它的时间轴规范只有 20 行（基线 1px、圆点 r=4、上下交替、间隔要诚实），
其中「时间刻度必须诚实：间隔不等就不要等距画」正是本项目日期型的核心设计 ——
它写成一句原则，本项目做成了可执行判据加实测门槛。

## 执行处

仅文档，无判据。这一条记的是**不做什么**，没有可执行的判据；
它的作用是在有人再提「要不要学 diagram-design」时，先读这一条。

## 后果

- 那两条「值得学但现在不做」的（无障碍契约、拆分门禁）挂在这里等条件成熟，不是永久否掉。
  条件分别是：愿意接受一次产物变更；愿意做一次带完整回归保护的重构。
