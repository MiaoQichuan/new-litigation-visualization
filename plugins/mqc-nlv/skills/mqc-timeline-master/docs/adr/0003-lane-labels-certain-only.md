# ADR 0003 — 侧标签只许写材料上写着的身份，不许下法律定性

**状态：** 已采纳（2026-08-19）

## 背景

作者定的：两个象限上的文字必须是**百分百确认的客观事实**，或**有明确材料出处的一方主张**；
不能确认就干脆不写 —— 要有谦抑性。

实错一次：七份材料全部出自原告一方，图上却标着「原告主张 / **被告自认**」，而「自认」二字
整份材料里一个字都没有（付款计划原文写的是「我司 2021 年的逾期货款」）。最能说明问题的
对比：**同一批材料里 5 条卡片正文全部通过子序列核验，两个侧标签一个字都在材料里找不到** ——
正文有「只许删减不许改写」的铁律管着，侧标签当时没有任何来源约束。

## 决策

两条纪律（`[C18]`，`check_model_output.check_lane_labels`）：

1. **不许含法律定性**（自认、承认、否认、抗辩、违约、侵权、恶意、责任、属实、存疑…）。
2. **两侧必须出自两方各自的材料**：判决书可以（法院居中记载诉称与辩称）、起诉状对答辩状
   可以；**只有一方的材料就是单侧**，不分侧、不出标签。

关键的一层：**同一个词的合法性取决于它出自谁的材料**。「被告主张」写在判决书里可以，
写在原告的起诉状里就不行 —— 那是原告转述对方的话，而转述人自己是当事人、有身份性。

## 否掉的替代

- **照搬子序列铁律，要求侧标签是某句的子序列。** 办不到：侧标签只有四五个字却要概括一整侧，
  「供货方」「采购方」这些好标签往往不是原文的连续片段。照搬会把可用标签全禁掉，
  等于逼人不写，与「说得出就写」相反。
- **靠白名单认「哪些词能写」。** 与 ADR 0005 那次同样的陷阱：能写的词无穷（公司名、人名、
  简称），白名单必然漏。
- **不管，靠自觉。** 实测证明靠不住 —— 我自己就在有铁律管正文的同一批材料上，
  给侧标签写了法律定性。
- **给侧标签也加一个 relation 之类的字段。** 这里不需要：法律定性的词是**有限的一小类**，
  词表够用；而且这条**只拦不放**，拦住等于退回不出标签（图照样画得出），
  不存在漏报成错图的风险。这与 ADR 0005 的取舍不同，原因就在「无穷」与「有限」之别。

## 执行处

`check_model_output.check_lane_labels`（标记 `[C18]`），管线在 `stage_render` 调它；
`tests/run_checks.py` 八条判据（三条该拦、五条该放，含判决书与两方各自提交两档）
加一条接线检查。

## 后果

- 改成单侧还有意外收益：那张图的容量从 42 字涨到 140 字（不必分层），正文能照抄原文写全。
- 词表要维护。新出现的定性词要补进 `_VERDICT_WORDS`，补的时候在守卫里加一条用例。
