# ADR 0003 — 模型作判断，但判断带标

**状态：** 已采纳

## 背景

大事记表与法律关系图的纪律是「模型不作判断」。本 skill 不能照搬：
要件审判九步法与请求权基础的推演本身就是法律判断，拒绝判断等于拒绝做这个 skill。

## 决策

判断照做，但分两档，并承九步法 skill 的三标出厂纪律。

- **可出，须带三标**：请求权基础、构成要件拆解、抗辩四分法归类。
  三标＝法律层面置信 ／ 证据层面置信 ／ 依据来源。两层置信必须分开评，不得合成一个模糊分数。
- **只给方向，结论留空**：证明前景、决定性要件排序、法院另作定性的风险。
- **一律照录**：四段攻防的正文取自起诉状、答辩状、代理意见原文。

## 为什么第二档必须留空

一个可以被后续步骤读取的结论字段，标不标「仅供参考」都会被当成结论用。
下游按争点分组、按前景排序时不会去区分那行小字。
