# ADR 0001 — 不做分图

**状态：** 已采纳

## 背景

主图是索引层，曾设想每个决定性要件再出一张展开的分图。

## 决策

不做。详细内容进分析表。

## 理由

四段攻防本身就是表的形状：主张、回应、反制、再回应是四个固定格子，一个要件单元就是一行四列。
画成图只是给表加了框线与箭头，不产生新信息。图值得画的是表达不出来的关系（一份证据同时支撑两段、
定性之争一垮下面全垮），那些已由主图的深红与对位线承担。

## 否掉的替代

- 「分图烧 token」不是理由：图由确定性脚本画，模型只出一次 JSON，画一张与画十张模型开销相同。
- 「按决定性要件排序只画前一两张」：仍然要为分图维护一套独立几何与守卫，成本在守卫不在渲染。
