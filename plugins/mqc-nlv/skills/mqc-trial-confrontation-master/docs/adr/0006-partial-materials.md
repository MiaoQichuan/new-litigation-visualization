# ADR 0006 — 材料不全要能跑完，但代价必须留痕

**状态：** 已采纳

## 背景

完备性对账原先是一刀切：未读页不为零即拒绝出图。
这条守的是「材料丢了要报错」，可它同时也挡住了另一件完全正常的事——
律师手上本来就只有一部分材料。庭前对方答辩状还没交换、质证意见要开庭才见、
调取的证据还没到，这是庭前推演的常态，不是事故。按旧规则，绝大多数真实场景跑不了。

同一处还藏着第二个问题。空段一律写成「（无书面记载）」。
但「对方确实没写这一段」和「我没拿到对方的文书」法律含义完全不同：
前者庭上可以据以主张对方未答辩，后者只是自己信息不全。
写成同一句话，等于在图上替对方说了他没说过话——与 A4 绝不编造同性质。

## 决策

对账分三态：已读 / 律师明示不读（`waived`）/ 该读没读。只有第三态拒绝出图。

casefile 顶层加 `scope`，`obtained` 与 `not_obtained` 两份清单。
每一处空段的来源文书都必须在其中之一里表过态（S1），表不了态就报错。
缺位文案随之分开：已在手的写「（无书面记載）」，没拿到的写「（未获取：答辩状）」。

图底如实写明材料范围，并注明该部分攻防以「未获取」留位、不作对方未主张处理（T5）。

## 理由

把「跑不跑得动」和「说不说得清」分开。
材料不全不该阻断出图，但不能让读图的人以为这张图看过全部卷宗。
代价留在图上，比拦住不出更有用——律师看得见缺口在哪，才知道下一步要去调什么。

## 代价

多了一处要律师填的东西（`scope`）。但这本来就是他脑子里已有的信息，
而且填不填得出来，恰好就是他对自己手上材料心里有没有数的检验。
