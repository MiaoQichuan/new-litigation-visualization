# 庭审对抗图 · 版面约束

每条都可机验；任何一条不成立即拒绝出图，不得降级硬画。
编号 M 主图版面 · R 走线 · T 索引表 · L 逻辑。

## M 主图版面

- T7 交付面只出中文，不漏数据结构。内部改成结构化字段（程序站三项分列）之后，
      出表那边若没跟着改，会把对象原样拼进单元格，表里印出一行 Python 字面量。
      出表期扫产物自证，发现字面量即拒绝交付。
      **凡填进 casefile 的东西都要有出口**：填了却不出现在图或表里的字段，等于让律师白填。
      自检把 casefile 摊平，逐字段去产物里找，找不到即报。实测抓到四处：
      整块诉请固定（J 组校验的全部产出）、决定性要件的「真伪不明的后果」、
      三标之三的立场方向，以及一个谁都不知道还在的死字段 `counter_target`
      ——只存在于示例数据里，无代码读、无文档提。
- T8 母表只有一张工作表，全部行可见，不折叠。节序按办案顺序：
      一、诉请固定（先看要什么）；二、要件与攻防（再看怎么打）；三、案件与程序（辅助，放最后）。
      程序站与材料范围挪到最后，冻结到列头时冻住的就只有诉请那几行，表头不占半屏。
      冻结设在列头行下方，编号列一并冻住，横滚时对得上行。
      层级只用四档字号做出来，不靠拆表也不靠藏：大标题 16（左对齐、单占一行，其下不留空行）、
      分节标题 12、争点板块行 11、正文一律 10.5。正文字号不得忽大忽小。
      走过两条弯路：先是拆成两张工作表，再是把说明区设成默认折叠的分组——
      后者更糟，等于把内容藏起来回避冻结的丑，打开表前十几行一片空白。
      对的办法是把辅助内容挪到后面，而不是藏起来或另开一张表。
- T11 线一律细，层次只靠灰度分三档：分节界限与列头用深灰，争点板块用中灰，正文用淡灰。
      先用过 medium 做分节与列头，太重；细线加深色已经够把界限说清楚，再粗就抢了正文。
- T10 列宽只有三档：短 12 / 中 26 / 长 46。逐列拍一个数字，宽窄会毫无道理地跳，
      且总有几列窄到读不下去——「法律上能否成立」原先 19 字宽，里面却要装四段主张。
      说明性的整行合并单元格，行高要给足，别把字挤没。
- T9 交付面的行文规矩：正文里不用破折号，标签与内容之间用冒号（「管辖：」而非「管辖——」）。
      中文与中文标点用宋体，英文与数字用 Times New Roman，同一格内按字符集分段着色；
      弯引号归中文侧。这些在写入单元格时按字符集自动分段，不靠人记。
- C3 母表不用底色。层级只靠字号、加粗与线：列头加粗压一条粗下线，板块行加粗放大压一条细上线。
      列头先是整行深红、后来改深灰，两种都是拿一条色带去分层——一条都不该有。
- C2 红只标决定性要件：图上是中轴卡与其走线，表里是那一行的编号。
      不做列头底色、不做小标题颜色。母表原先列头整行深红、每个请求权基础行又是红字，
      一张表十八处红，真正该被一眼找到的那一处反而淹了。
      上限与图的 L4 同一条纪律：至多两处；三处及以上不标，改在小结里写明共几处、分别是哪几个。
      出表时读回产物数深红，超量拒绝交付。
- C1 全套只有一个红：#991B1B。图与表同一个值，源码里不许出现第二个红系颜色。
      自检按 RGB 分量判红系，不按变量名——改个名就绕过去了。
      实测撞出过：图用 #991B1B、母表用 #9E2A2B，肉眼分不出，图表摆在一起才露；
      另有一处判据自己写成 #8C1C1C，与渲染对不上，那条判据一直静默算出 0。
- M1 三栏等宽。早先曾规定中轴不窄于两侧 1.6 倍，出图后否掉：中轴过宽会让法院审查看着比双方还重。
- M2 三栏加两条栏间通道，精确等于可用宽度（页边之内），误差为零。
- M3 行组高 = max(左栈总高, 右栈总高, 中轴需高)。左右两栈把行组撑出来，中轴不参与加高。
- M4 中轴卡高 = 行组高。三者中线因此重合，母线两腿天然等长，单干是一条水平直线。
- M5 同栏诸卡等高，取该组内最高者。
- M6 纵向一律用绝对间距（比例因子的倍数），不用行组高的百分比——百分比会让高组的留白被放大。
- M7 抬头与第一条虚线的关系由反解确定：行组顶 = 抬头底缘 + 呼吸位 + 虚线上移量。不得各写各的。
- M8 卡内文字只折行不截断；超过行数上限则截到上限并标「全文见表」。中轴卡因高度即行组高，行数上限单独放宽。
- M10 卡内留白由 PADY 一处定：文字块的上沿与下沿按字形常量（上沿 0.88×字号、下沉 0.22×字号）量出，
      上下留白各等于 PADY。卡高与每一行的基线出自同一个函数，改一处两边一起动。
      早先高度按「2×PADY + 标题行高 + 正文行高」估，漏掉标题与正文之间的呼吸位与字形下沉，
      凡高度恰等于自身所需的卡，下留白被吃掉约半行，正文贴着卡底；截断标注还会压在末行正文上，
      故截断标注另占一行。
- M10 标题一律贴卡顶左上排，卡高再怎么被撑大都不跟着下移——三栏的标题因此在同一水平线上。
      自检量各卡标题上沿到卡顶的距离是否一致。
- M11 只有正文在「标题下沿 → 卡底」这段剩余空间里纵向居中。中轴卡的高度是行组高、
      由两侧撑出，侧栏卡的高度取同组最高的那张，正文照顶排会在下方留出一大块空；
      而整卡一起居中又会把标题带下去、三栏标题参差。偏移允许是很小的负数：
      标题与正文之间的呼吸位本就比字形下沉多出一点，紧排的卡天然偏下约两像素。
- M12 卡底留白不得小于卡顶留白。这条是 M11 的补充：正文一居中，卡高算错就被吸收掉了
      （正文跟着上移，上下仍然相等，只是一起变窄），必须另量一个绝对值才露得出来。
- M9 字宽按字符集算：中文全宽 = 1.0×字号，西文数字 ≈ 0.5×字号。曾按 0.52 一刀切，容量算大近一倍、正文溢出卡框。

## R 走线

- R1 汇聚式：同侧诸卡各出一条短腿落到通道正中的母线，母线单干进入中轴卡边框中点。同侧只有一张卡时退化为直连，不并母线。
- R2 首尾两条腿与母线必须是同一条连续折线，两个拐角由圆弧倒角处理。两条独立路径端点对接一定缺一块半线宽见方的角。
- R3 中间诸腿是 T 字接头：直线 + 实心圆点。圆点颜色与半径跟随该束（深红束用深红）。
- R4 圆角半径 = 2.4 × 线宽，切掉拐点顶点约一个线宽。改线宽圆角自动跟随，不得各自写死。
- R5 箭头固定 10px，`markerUnits="userSpaceOnUse"`；`refX` 按 cover = 2.0 × 线宽算出，不得钉死。红灰箭头同大小。
- R6 走线终点按 cover 留白，箭头尖落在缝里，不压模块。
- R7 任何走线不得穿过非端点卡片或边标签（出图前逐段对所有障碍做矩形相交自证）。
      自证必须覆盖全部走线：曾只把每侧最后一条线送进自证，母线与中间腿是漏检的。
- R9 边标签（材料来源）贴卡外缘排：左栏左起、右栏右止，不居中在卡缘与母线之间——居中时字宽压过
      通道中线，母线竖段从字上穿过，另一头还探进卡内。纵向让开母线：首卡的标签在其引线之上、
      末卡的在其引线之下，两处都在母线竖段的上下端之外。每侧至多两张卡，故不存在无处可让的中间卡。
      标签框与卡片一同作为障碍进入穿越自证（R7），走线压字与走线穿卡同样拒绝出图。
      标签内容取自数据（A3），不写死文书名；宽度不得超过栏间通道，超出即拒绝出图并报出可用字数。
- R10 底部结论条的宽度由文字反解，不按幅宽的固定比例。比例钉死在 0.46 时，
      行组标题一变长，字就从红块里溢出来。
- R8 对位链：第 i 张左卡对第 min(i, 右卡数−1) 张右卡。第 0 对走行组上方，其余走下方——两处都在中轴卡竖向范围之外，故不穿卡。对位线双向箭头，颜色与线一致。

## T 索引表

- T1 圆角细框套住整张表；标题居中在框内顶部，其下一条横线；列头加粗无底色，其下一条横线；行与行之间不划线。
- T2 列的起止点与横线的起止点共用同一内缩值，所有文字落在线内，左右都不出头。
- T3 结论用深红实心块置于框外右下；判据与图例用小字置于左下。
- T4 表按末组底缘定位，不按总高——总高含着留给下一行组的组间距，用它定位会凭空多出一大段空白。

## L 逻辑

- L1 版面跟着材料走：有几段攻防就出几张卡，没有的那一段不出卡。可能的编排只有四种——
      左2右2 / 左2右1 / 左1右1 / 左1右0（对方尚无任何回应，右侧空着，不画母线与对位线）。
      请求方至少一张、至多两张，抗辩方 0 到 2 张。
      空段的归因（无书面记载 / 未获取某文书）落在分析表与图底的材料范围里，不在图上立框：
      凭空立一个「未获取」的框，读图的人会把它当成对方真有这一手。
- L2 左1右2 不成立——有再回应必先有反制。数据层（B2）与几何层（L2）各拦一道。
- L3 深红由规则算，不由人标：有争议 × 客观证明责任在提出请求的一方 × 现有证据未达证明标准，三条同时命中即决定性要件。
- L3b 从属性排除：所属请求权基础为辅助规范、或与主债聚合而不独立存在的（如孳息、资金占用费），
      纵三条全中也不计入决定性要件——它随主债同进退，不是独立的决定性要件。此条由真实案件撞出。
      **例外（第二件真实案件撞出）**：从属请求若另有独立指向它、而不指向主债的抗辩
      ——双方均违约、债权人迟延受领、约定或法定的免责事由——则不再随主债同进退，须单列。
      判断的办法是问一句：对方有没有一条只打这个从属请求、不打主债的理由。
      一件建设工程案里，工程款 583335.06 元全额支持，利息却因「双方都违反合同各自承担责任」
      （被告未付清款、原告未提交书面竣工验收报告）被单独驳回。
      推演已在「自陈不利事实」一栏记下了那份未提交的验收报告，却因这条排除而没让它上图。
- L3c 行组的单位是「有争议待证的构成要件」（B5），不是诉请。行组标题＝对抗部分名 + 要件名，
      图上看得出这一组属于哪一项请求；索引表第一列用要件编号，不用长标题。
- T5 图底写明本图所据的材料范围，缺哪几份文书如实列出，并注明该部分攻防以「未获取」
      留位、不作对方未主张处理。这行不用深红——它是提示，不是强调，占了深红会稀释强调。
- L4 图上至多强调 2 处；自检数的是深红色块的个数，不是深红出现的总次数。
      走线与圆点跟着被强调的部分数走，总次数的上限只能拍脑袋定，
      且图底多一行红字就会破（实测：加一行材料范围提示，13 处，旧判据直接拒绝出图）。；规则算出三处及以上转入分散态：全图不用深红，索引表仍如实标出
      命中项，底部结论条写明共几处、分别是哪几个。判定本身不封顶。
      由真实案件撞出：一件争点零散的买卖合同仲裁，三项请求同时命中 D1 三条判据，
      按旧规则直接拒绝出图。代码不得替律师挑出前两个（违反 A2）。
- L5 反诉角色反转：卡片按 role 落栏，不按数组位置。
