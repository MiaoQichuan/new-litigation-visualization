# 庭审对抗图大师 · 摄入与可验证抽取

## I 摄入（承大事记表大师的读取层，判据不变）

- I1 探测按**逐页可读字符数**，不看 pdffonts 有没有字体。一份纯图 PDF 可能在末页挂一个空字体，
     按字体表判会把它误判为文字型。
- I2 计数前先剥页码标记（`- 12 -` 这类）。只印着页码的尾页是空白页，不是不可读页。
     实测：一份 20 页文字型判决书因末页仅 4 字符被误判为 mixed。
- I3 文字型直读；扫描件 150 DPI 栅格化，由模型逐页读图写**转写稿**，转写稿作为材料进管线。
     不引 OCR。读不读、读哪几页由律师定，代码只报预估成本。
- I5 摄入先按格式分派，认不出的格式必须显式报错，不得静默归入扫描件那条路。
     只处理 PDF 时，非 PDF 文件取不到页数 → 判 0 页 → 判为扫描件 → 栅格化产不出图 →
     模型什么也读不到；而对账的声明页数按页数求和，0 页材料不产生任何未读页，
     于是在材料已经丢掉的情况下报平。实测：律师传的 docx 起诉状与手机拍的照片两样都
     被静默丢掉。现在图片本身就是一页待读图、不再栅格化，docx 与纯文本零依赖抽正文、
     抽不出即报错，其余扩展名一律拒绝摄入。
- I4 完备性对账：声明页数与已读页数必须相符，未读页不为零即拒绝出图。
     扫描件上句数对账会变成自证，**外部锚**（卷宗目录页码、页脚印刷页码）是唯一把手。
     **对账分三态**：已读 / 律师明示不读（`waived`，对照用的判决书、与争点无关的附件）/
     该读没读。只有第三态拒绝出图。材料本来就没有的写进 `scope.not_obtained`，
     有但决定不读的写进 `waived`——两者都不许当成已读，但都不阻断出图。
     材料不全是常态，材料丢了才是事故，混在一起等于绝大多数案子都跑不了。
     **份数与页数两轨都要平**：只按页数求和抓不住整份丢失的材料，须另列未读材料清单，
     待读图的材料在模型写出转写稿之前一律计入未读。

## J 诉请固定（九步法工序一，可机验）

每项诉讼请求按类型固定，缺项即报错。

| 诉请类型 | 必填项 |
|---|---|
| `给付钱款` / `给付实物` | 给付主体、标的种类、金额或数量、**构成及计算方法** |
| `履行行为` | 履行内容、履行方式、**是否便于执行** |
| `多被告担责` | 各被告的**责任性质**（连带／按份／补充）与份额 |
| `确认` / `形成` | 确认或形成的具体对象 |

- J1 类型取自封闭表，表外类型一律拒绝并报出，不得自行造类。
- J1b 主张确定数额的诉请必须附结构化构成明细 `breakdown`（项目／金额／依据），
     合计与主张额相符、每项都有依据。取不出确定数额的（如「按实际发生额」）不核算。
- J2 「构成及计算方法」「是否便于执行」「责任性质与份额」三项最常被略过，
     而它们正是对方诉请的固定漏洞所在，本身即是攻防点。缺项须显式标注，不得留空蒙混。

## K 抗辩归类（四分法，可机验）

- K1 归类取自封闭表：`否认` / `权利障碍` / `权利消灭` / `权利受制抗辩权`。
- K2 **举证责任由归类机械决定**，不由模型另判：`否认` → 仍在提出请求的一方；
     其余三类 → 抗辩的一方。归类与举证责任不一致即报错。
     —— 分错类的直接后果是白背一个举证负担，归类一错，攻防的落点整个挪位。
- K3 每条归类必须附**三问路径**：
     一问 是否称该事实不存在 → 是则 `否认`；
     二问 是否称权利自始未发生 → 是则 `权利障碍`；
     三问 是否称权利曾存在而已消灭 → 是则 `权利消灭`；否则为 `权利受制抗辩权`。
     路径缺失即报错，供律师复核归类是否正确。
- K4 材料未明示时按对方原话照录，归类标【待核验】，不得替对方定性。
     **【待核验】只表示归类待律师复核，不豁免机械判据**：校验时先剥掉标记再查 K1／K2／K3。
     否则给归类加四个字，举证责任与三问路径两条一起失效——真案子里一条
     「权利受制抗辩权【待核验】」就把两项检查全绕过去了。
