# 庭审对抗图大师

按要件审判九步法与请求权基础，把案件材料推成**一张庭前对抗图**与**一份分析表**：
左为提出请求的一方、中为法院审查、右为抗辩的一方；深红标出决定性要件；本诉与反诉同图。
供律师团队庭前推演与向当事人汇报，**不对法院出示**。

## 适合做什么

- 庭前把各方观点排布起来：谁提出什么请求、法院会审什么、对方会怎么应、哪一处决定成败
- 按请求权基础拆构成要件，逐条标举证责任、证明前景、待补材料
- 抗辩按四分法归类（否认／权利障碍／权利消灭／权利受制），举证责任随归类机械确定
- 本诉与反诉放在同一张图、同一份表；抵销、违约金酌减、另案主张单列，不混进抗辩
- 材料不全也能出图：每处空段如实写明「没有／未获取／明示不读」

## 不适合做什么

- 预测胜负、给胜诉率（证明前景只给方向，结论留给律师）
- 对外呈报：图上有我方薄弱点与待补证
- 案件经过时间轴、主体关系图（用对应的技能）
- 确认之诉、形成之诉的要件拆解：标出边界后转法律关系分析法

## 三步上手

```bash
python3 scripts/pipeline.py --check            # ① 看本机能出什么（Excel、SVG、PNG 各缺什么）
python3 scripts/pipeline.py --demo             # ② 随包示例跑一遍，产物在 ./庭审对抗图-示例
python3 scripts/pipeline.py 案件.json 出图      # ③ 换成您的案件；末尾可加 1=Excel 2=SVG 3=PNG 或「全部」
```

在 AI 助手里直接说：「用庭审对抗图大师，把这个案子的争点推一遍」，再把起诉状、答辩状、证据目录交给它。
它按 `references/casefile-guide.md` 把卷宗读成 `案件.json`，自查全绿后出图出表。

## 输入与输出

- **输入**：起诉状、答辩状、证据目录、代理意见、庭审笔录（PDF 含扫描件／图片／docx／纯文本）。
- **输出**：分析表 Excel（17 列，按九步法从左往右读）+ 对抗图 SVG（默认）；PNG 可选。
- 同一份输入永远出同一张图，便于复核。

## 可靠性

- 图由表派生，表是唯一的信息源；每次出图都做**图表一致**与**图几何**两项自检，不过不交付。
- 诉请固定、抗辩归类、金额核算、材料对账开跑前机验，哪一条不合规就拒绝并说清怎么改。
- 报错说人话：路径打错、JSON 写坏、骨架缺字段、缺 openpyxl、PNG 转不出来，都说清是哪一处、怎么办，不甩堆栈；PNG 出不来不连累 Excel 与 SVG。
- 包内带完整回归：`python3 tests/run_checks.py`。

## 安全与隐私

- 纯本地运行：**不联网、不调用任何外部 API、不需要凭据**。
- 只读您指定的材料，只往您指定的目录写文件；不替您脱敏，涉密案件请先自行处理。
- 判断带标：每条要件带法律置信、证据置信与来源；条号案号不编造，拿不准的标【待核验】。

## 依赖

- 对抗图 SVG：只用 Python 标准库。
- 分析表 Excel：`openpyxl`（`pip install openpyxl`）。
- PNG（可选）：`pillow`、`numpy` 加任一转图工具（cairosvg／Inkscape／LibreOffice／resvg-js／Playwright）。
