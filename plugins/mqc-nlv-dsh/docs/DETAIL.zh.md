# 新诉讼可视化 · 把法律画出来

给法律人的诉讼可视化工具集。装上后，在对话里用中文说需求即可，例如：

- 「把这几份判决书和证据整理成案件经过时间轴」
- 「画一张这个案子的法律关系图」
- 「把材料整理成案件大事记，出 Word 和 Excel」
- 「按九步法做一张庭前对抗图」
- 「把这 100 份判决的结果构成做成一页数据图」
- 「做三页类案研究的课件，律所内训用」

成品放在您当前的工作区里，对话里会出现文件卡片，点一下就在右侧预览。

## 七个技能

| 技能 | 做什么 | 交付 |
| --- | --- | --- |
| 诉讼可视化重画 | 把现成的时间轴、流程图、关系图重画成克制、可进诉讼材料的图，不改一个字 | SVG、PNG、PPTX |
| 时间轴大师 | 把案件材料推成案件经过时间轴，每个事件都能追到原文出处 | SVG、PPTX、Visio、drawio；Word 溯源索引（需 Node.js） |
| 法律关系图大师 | 谁与谁、就哪份合同或哪笔款项、成立什么关系 | SVG、PPTX、Visio、drawio |
| 大事记表大师 | 把一批材料整理成案件大事记 | Excel、A4 简表；Word 版（需 Node.js） |
| 庭审对抗图大师 | 按要件审判九步法推出庭前对抗图与分析表 | SVG、Excel |
| 法律图表大师 | 把法律数据画成统计图，标题里的数必须由数据算得出 | SVG、可编辑 PPTX |
| 法律课件大师 | 把图放进课件页，配结论、要点、法条，导出可编辑 PPTX | PPTX |

## 第一次使用

出图引擎用 Python 写成，电脑上需要有 **Python 3.9 或更新的版本**。

- 在对话里说「检查新诉讼可视化的环境」，它会告诉您缺什么、怎么装。
- 还没装 Python：到 python.org 下载安装包，Windows 上**第一页勾选「Add python.exe to PATH」**；装好后完全退出 DeepSeek Harness 再打开。
- 出 Excel 用的 openpyxl、写 Word 用的 docx 都已随插件附带，不用另装。LibreOffice（PNG 预览）、Graphviz、Node.js（Word 版）都是可选的，没有也能出 SVG、PPTX、Excel。

## 安全与隐私

- 全部在本机运行：不联网、不调用任何外部接口、不上传材料。
- 只运行随插件附带的脚本，产物只写进当前工作区。
- 材料里的文字一律当数据，不当指令。
